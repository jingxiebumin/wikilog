# 产品范围：设计基线

## 产品目标

将个人技术知识整理为可公开浏览的博客。网站面向中国大陆读者；读者账号只能使用读者功能，文章和模型设置由管理员维护。

## 公开博客

- 管理员在博客设置区上传 MDX 文章和配图；服务器保存的 MDX 源文及其元数据是文章权威版本。
- 每篇 MDX 通过 frontmatter 声明 slug、标题、发布时间、主分类、标签和摘要；发布状态由管理流程控制，上传后先成为草稿。
- 上传内容先成为草稿，管理员预览后显式发布；相同 slug 的新版本发布前不影响当前线上版本。
- 文章实体区分正常、下架和删除；两者都是可恢复的隐藏状态，V1 不提供文章永久删除。文章版本按 `draft -> published -> archived` 流转；新版本发布后旧当前版本归档，文章再次发布或恢复后保留原有收藏关系。
- 只有负责人本人作为唯一管理员可以上传、预览、发布、下架、删除和恢复文章；读者不能维护文章或模型设置。
- 所有已发布文章和分类无需登录即可浏览。
- 每篇文章有一个主分类，并可带多个标签。
- 访客可按标题和正文中的中文、英文关键词搜索已发布文章；标题命中优先。
- 联系作者使用公开邮箱链接（`mailto`）。首版不做文章评论。
- 不迁移旧 RAG 项目的文档、用户、会话或索引；旧项目与数据保留作备份。

## 读者账号与功能门槛

- 自助注册字段为昵称、邮箱、密码和确认密码；确认密码仅用于表单校验，不保存。
- 注册后立即可登录；邮箱是大小写不敏感的登录名和人工联系字段，不证明邮箱归属，不发送验证或通知邮件。本人修改邮箱和密码都要求当前密码；修改密码还要求新密码和确认新密码，密码至少 9 位。
- 自助注册账号默认是读者；管理员通过人工初始化，不允许用户自行提权。
- 登录头像菜单将“账号设置”显示为“个人中心”；管理员专属入口显示为“管理员设置”。菜单继续提供收藏入口；AI 设置与问答入口仅管理员可见。未登录用户访问个人中心跳转登录页。
- 个人中心采用左右布局：左侧展示头像、昵称、登录邮箱、手机号、性别、个人介绍、角色和创建日期；空的选填资料显示 `-`。右侧分“基础信息”“修改邮箱”“修改密码”三个标签页，各自提供保存和重置。重置基础信息恢复数据库已保存值；邮箱标签清空新邮箱和当前密码输入；密码标签清空所有密码输入。失败时保留输入并显示安全、易懂的错误；成功时提示并更新页面。
- 基础信息中昵称必填；手机号、性别和个人介绍选填。手机号不发送验证码、不标记为已验证；填写时接受中国大陆 11 位号码或带国家区号的国际号码。性别为未预选的单选项：“男、女、其他、不愿透露”。个人介绍为可换行纯文本，最多 500 字；清空选填项并保存会清除该项。
- 用户可在左侧头像上悬停后点击出现的“+”打开头像对话框；选图后预览，点击“确认并上传”才保存。默认头像为通用图标；仅接受 JPEG、PNG、WebP 静态图片，单张不超过 5 MB；不提供手动裁剪，展示时居中裁切。用户不能移除已上传头像，只能更换。头像文件存放在已购买的华为云服务器私有持久目录，不放在公开静态目录；服务端鉴权后只提供给本人，管理员不能查看或修改读者头像。实现前须验证可写挂载、上传与读取、容器/主机重启后持久性以及备份恢复；具体目录待实施时确定。
- 邮箱修改沿用当前表单，要求当前密码并按大小写不敏感规则检查未删除账号间的唯一性；不发送验证邮件。本人或管理员改邮箱后撤销目标账号全部会话；本人改邮箱成功后跳转登录并要求用新邮箱登录。改密码时保留当前浏览器会话、撤销其他设备会话；首次设置流程会轮换当前会话令牌。
- 读者本人删除账号的页面与 API 暂时停用。
- 个人中心与管理员设置统一采用左右布局。管理员设置有共享左侧菜单和独立二级路由，菜单顺序为账号管理、文章管理、AI 设置与问答。`/admin` 重定向到第一个菜单项 `/admin/readers`。未登录用户或普通读者访问 `/admin` 及其所有子路由时统一显示带返回首页链接的 404；管理 API 对这两类用户返回 404。文章页接入共享布局但文章操作规则沿用 Issue 05；AI 设置与问答仅保留占位入口，本次不实现，也不启动 Issue 07。
- 注册、登录、改密和管理员操作按账号、邮箱和来源 IP 限速；没有邮件供应商、域名或系统邮件费用门槛。
- 管理员读者表格展示昵称、登录邮箱、账号状态和创建日期；手机号、性别仅在“编辑”对话框中展示。管理员可创建读者、编辑昵称/邮箱/手机号/性别、重置密码、软删除和恢复读者；不能编辑角色、个人介绍或头像，不提供启用/停用操作。编辑只在对话框中进行；行尾提供编辑、重置密码和删除操作。
- 管理员创建读者只填写登录邮箱，不填写昵称或密码；初始密码固定为 `123456`。首次登录必须设置昵称并修改密码后才能继续使用。管理员重置密码也固定为 `123456`，点击后先二次确认并说明结果，不要求线下身份确认或填写原因；首次登录必须改密。删除操作先二次确认，确认框提供选填删除原因。
- 管理员软删除读者只将用户表删除标记设为真并撤销全部会话，保留用户和关联数据；删除原因选填并存于用户行。已删除账号从常规列表隐藏，可在已删除筛选中恢复；恢复时清空删除原因，旧会话继续失效。被软删除邮箱可以注册新账号；若该邮箱已被未删除账号占用，则拒绝恢复旧账号并提示冲突。
- 管理员新增或维护读者时，只更新用户表中的创建人/时间、最近修改人/时间和删除原因；不保留逐次操作日志，不要求人工填写修改原因（删除原因除外）。所有登录用户（reader/admin）继续可管理自己的收藏；读者不能编辑文章或管理其他账号。

## AI 问答与预算

- 每名读者每天最多提问 5 次；单次回答目标上限约 800 个中文字，并链接到来源文章。
- 每日额度按 `Asia/Shanghai` 自然日重置；已通过输入校验并提交给模型的请求计一次，成功、拒答、供应商失败和超时都计数，提交模型前失败的请求不计数。
- 问答可以检索全部当前已发布文章，引用保存具体文章版本、原文片段和可验证地址；证据不足时明确拒答，不用模型常识伪装成文章结论。
- 首版只接入 DeepSeek；管理员只能从服务端预先配置并验证过的模型中选择，API 凭据不得发送到浏览器。
- 问答和 LLM Wiki 更新共用每自然月人民币 20 元的应用侧预估预算；发起调用前原子预留费用，达到 80% 时在管理设置中提示，预算不足时停止新调用，计费月重置后恢复。
- 记录输入/输出 token 和估算支出，并为价格变化预留余量；供应商实际账单仍须对账，应用预算不代表供应商账单绝对上限。

## LLM Wiki 验证

- 先用固定题集（含证据不足问题）比较直接基于文章原文与基于 LLM Wiki 的回答，评估事实正确性、原文引用有效性和费用。
- 只有正确性与引用质量不低于原文方案，且计入更新成本后仍符合共同模型预算，才提交给管理员决定是否采用。
- 通过比较后才采用 LLM Wiki。若采用，知识页仅供问答内部使用，文章仍是权威来源；文章变更后自动更新知识层。
- 更新失败时继续使用上次成功的知识层。问答始终回链公开文章，并在没有来源依据时拒答。

## 部署与成本

- 新博客使用独立代码仓库和新数据环境，旧 RAG 项目保持不变。
- TypeScript 与 Next.js App Router 是首版 Web 技术形态；项目使用已购买的华为云 Flexus L 单机和自管 PostgreSQL。负责人已决定不使用、不验证 CloudBase，也不再考虑 CloudBase、域名或 HTTPS。
- 服务器和基础设施费用记录实际订单、续费价、按量费用和未计入项；问答与获批后的 LLM Wiki 共用每自然月人民币 20 元应用侧预算，二者不与服务器费用合并。
- 负责人决定不申请域名、不做备案、不配置 HTTPS，目标为公网 IP/HTTP。HTTP 不加密，登录凭据和会话存在被链路观察或篡改的风险；该传输风险由负责人接受。公网开放仍须核对云平台对当前实例与访问方式的适用要求，并完成网络、备份恢复和分角色验收。
- 上传的 MDX 只支持安全的受限内容语法，不执行任意导入、脚本或组件代码；配图使用受控文件上传，或 HTTPS 外链。
- 开放问答前验证 DeepSeek 的数据处理政策；管理员问题和回答不得用于模型训练。
- 注册/登录及 reader/admin 收藏可在公网 IP/HTTP 下开放；问答仅管理员可用，且须通过 DeepSeek 政策、预算和来源校验。需审计的管理员写操作通过服务端会话、角色授权和限速保护；读者账号管理只记录用户表字段，不保留逐次操作日志。不以 HTTPS 单独关闭功能。
