# 产品范围：设计基线

## 产品目标

将个人技术知识整理为可公开浏览的博客。网站面向中国大陆读者；读者账号只能使用读者功能，文章和模型设置由管理员维护。

## 公开博客

- 管理员在博客设置区上传 MDX 文章和配图；服务器保存的 MDX 源文及其元数据是文章权威版本。
- 每篇 MDX 通过 frontmatter 声明 slug、标题、发布时间、主分类、标签和摘要；发布状态由管理流程控制，上传后先成为草稿。
- 上传内容先成为草稿，管理员预览后显式发布；相同 slug 的新版本发布前不影响当前线上版本。
- 文章实体区分正常、下架和删除；两者都是可恢复的隐藏状态，V1 不提供文章永久删除。文章版本按 `draft -> published -> archived` 流转；新版本发布后旧当前版本归档，文章再次发布或恢复后保留原有收藏关系。
- 只有负责人本人作为唯一管理员可以上传、预览、发布、下架、删除和恢复文章；读者不能维护文章或模型设置。
- 所有已发布文章和分类无需登录即可浏览。
- 每篇文章有一个主分类，并可带多个标签。
- 访客可按标题和正文中的中文、英文关键词搜索已发布文章；标题命中优先。
- 联系作者使用公开邮箱链接（`mailto`）。首版不做文章评论。
- 不迁移旧 RAG 项目的文档、用户、会话或索引；旧项目与数据保留作备份。

## 读者账号与功能门槛

- 自助注册字段为昵称、邮箱、密码和确认密码；确认密码仅用于表单校验，不保存。
- 注册后立即可登录；邮箱是大小写不敏感的登录名和人工联系字段，不证明邮箱归属，不发送验证或通知邮件。修改邮箱和密码都要求当前密码；修改密码还要求新密码和确认新密码。
- 忘记密码不提供自助恢复。读者联系管理员，管理员线下确认身份后在受保护入口生成一次性临时密码；临时密码只显示一次，首次登录必须修改，操作记录审计信息但不记录临时密码。
- 自助注册账号默认是读者；管理员通过人工初始化，不允许用户自行提权。
- 登录头像下拉菜单集中放置账号设置、收藏；问答入口仅 admin 可见。管理员设置入口打开工作台，并分别进入账号管理、文章管理和 AI 设置/问答页面；避免把不同管理流程堆在一页，也不建设复杂指标仪表盘。
- 注册、登录、改密和管理员操作按账号、邮箱和来源 IP 限速；没有邮件供应商、域名或系统邮件费用门槛。
- 所有登录用户（reader/admin）可收藏文章并管理自己的收藏；仅管理员可以使用 AI 问答和管理自己的问答会话。reader 可删除自己的账号及站内个人数据；reader 不能编辑文章或管理其他账号。
- 管理员账号管理支持人工创建 reader、编辑 reader 的昵称和登录邮箱、启用/停用和临时密码重置；角色不可编辑，管理员账号不可经此页面删除。涉及身份确认、状态变化和资料修改的管理操作记录操作者、目标、原因及前后状态。

## AI 问答与预算

- 每名读者每天最多提问 5 次；单次回答目标上限约 800 个中文字，并链接到来源文章。
- 每日额度按 `Asia/Shanghai` 自然日重置；已通过输入校验并提交给模型的请求计一次，成功、拒答、供应商失败和超时都计数，提交模型前失败的请求不计数。
- 问答可以检索全部当前已发布文章，引用保存具体文章版本、原文片段和可验证地址；证据不足时明确拒答，不用模型常识伪装成文章结论。
- 首版只接入 DeepSeek；管理员只能从服务端预先配置并验证过的模型中选择，API 凭据不得发送到浏览器。
- 问答和 LLM Wiki 更新共用每自然月人民币 20 元的应用侧预估预算；发起调用前原子预留费用，达到 80% 时在管理设置中提示，预算不足时停止新调用，计费月重置后恢复。
- 记录输入/输出 token 和估算支出，并为价格变化预留余量；供应商实际账单仍须对账，应用预算不代表供应商账单绝对上限。

## LLM Wiki 验证

- 先用固定题集（含证据不足问题）比较直接基于文章原文与基于 LLM Wiki 的回答，评估事实正确性、原文引用有效性和费用。
- 只有正确性与引用质量不低于原文方案，且计入更新成本后仍符合共同模型预算，才提交给管理员决定是否采用。
- 通过比较后才采用 LLM Wiki。若采用，知识页仅供问答内部使用，文章仍是权威来源；文章变更后自动更新知识层。
- 更新失败时继续使用上次成功的知识层。问答始终回链公开文章，并在没有来源依据时拒答。

## 部署与成本

- 新博客使用独立代码仓库和新数据环境，旧 RAG 项目保持不变。
- TypeScript 与 Next.js App Router 是首版 Web 技术形态；项目使用已购买的华为云 Flexus L 单机和自管 PostgreSQL。负责人已决定不使用、不验证 CloudBase，也不再考虑 CloudBase、域名或 HTTPS。
- 服务器和基础设施费用记录实际订单、续费价、按量费用和未计入项；问答与获批后的 LLM Wiki 共用每自然月人民币 20 元应用侧预算，二者不与服务器费用合并。
- 负责人决定不申请域名、不做备案、不配置 HTTPS，目标为公网 IP/HTTP。HTTP 不加密，登录凭据和会话存在被链路观察或篡改的风险；该传输风险由负责人接受。公网开放仍须核对云平台对当前实例与访问方式的适用要求，并完成网络、备份恢复和分角色验收。
- 上传的 MDX 只支持安全的受限内容语法，不执行任意导入、脚本或组件代码；配图使用受控文件上传，或 HTTPS 外链。
- 开放问答前验证 DeepSeek 的数据处理政策；管理员问题和回答不得用于模型训练。
- 注册/登录及 reader/admin 收藏可在公网 IP/HTTP 下开放；问答仅管理员可用，且须通过 DeepSeek 政策、预算和来源校验。管理员写操作通过服务端会话、角色授权、限速和审计保护；不以 HTTPS 单独关闭功能。
