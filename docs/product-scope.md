# 产品范围：设计基线

## 产品目标

将个人技术知识整理为可公开浏览的博客。网站面向中国大陆读者；读者不能创建或维护自己的文章。

## 公开博客

- 作者在代码仓库中编辑 MDX 文章，并通过部署发布。
- 所有已发布文章和分类无需登录即可浏览。
- 每篇文章有一个主分类，并可带多个标签。
- 访客可按标题和正文关键词搜索文章。
- 联系作者使用公开邮箱链接（`mailto`）。首版不做文章评论。
- 不迁移旧 RAG 项目的文档、用户、会话或索引；旧项目与数据保留作备份。

## 读者账号与功能门槛

- 计划开放邮箱验证码自助注册，并限制邮箱及 IP 的发送频率。
- 只有在 CloudBase 邮箱代发能投递给公众读者、且费用和持续运行成本已验证后，才开放读者账号。
- 若邮件发送需要额外付费或不可靠，首发范围保持为公开博客和联系邮箱，收藏与问答延后。
- 账号开放后，读者可收藏文章、使用 AI 问答、查看并删除自己的问答会话；读者不能编辑内容。

## AI 问答与预算

- 每名读者每天最多提问 5 次；单次回答目标上限约 800 个中文字，并链接到来源文章。
- 证据不足时明确说明文章中没有足够依据，不用模型常识伪装成文章结论。
- 问答和 LLM Wiki 更新共用每月人民币 20 元硬上限；达到预算阈值后暂停新的模型调用，按下个计费月恢复。
- DeepSeek Flash 是首个待验证模型候选。记录输入/输出 token 用量并在上限前留出价格及汇率余量。

## LLM Wiki 验证

- 先用一组代表性问题，比较直接基于 MDX 原文的回答与基于 LLM Wiki 的回答，评估正确性、引用质量和费用。
- 通过比较后才采用 LLM Wiki。若采用，知识页仅供问答内部使用，文章仍是权威来源；文章变更后自动更新知识层。
- 更新失败时继续使用上次成功的知识层。问答始终回链公开文章，并在没有来源依据时拒答。

## 部署与成本

- 新博客使用独立代码仓库和新数据环境，旧 RAG 项目保持不变。
- 腾讯云 CloudBase 上海 PostgreSQL 作为国内访问、邮箱认证和持续费用的试点方案，不视为已锁定的长期供应商。
- 网站与数据库月度成本目标为人民币 20 元以内；有明确必要性时可以超过，但需先说明成本依据。
- 在试点中验证大陆访问延迟、公众邮箱验证码投递、Next.js 部署方式和试用结束后的持续费用；无法满足邮件或成本门槛时，先发布无需账号的博客。
