# 密码账号不依赖邮件服务

状态：已修订（2026-11-07）

## 决策

读者以昵称、邮箱和密码注册，注册后立即可以登录和使用已开放的读者功能。邮箱是大小写不敏感的登录名和人工联系字段，不用于证明邮箱归属，也不触发验证或通知邮件。注册、登录、修改邮箱、修改密码和管理员重置均不发送系统邮件。

忘记密码不提供自助恢复。读者联系管理员后，管理员通过线下渠道确认身份，在受保护的管理员入口生成一次性临时密码；临时密码只展示一次，读者首次登录必须修改。管理员重置记录操作者、目标账号、时间、原因和结果，不记录临时密码。

公开注册永远只能创建 `reader` 账号；管理员账号只能人工初始化。登录、注册、改密和管理员操作仍须服务端授权、限速、审计和通用错误处理。没有邮件供应商、域名或外部邮件数据处理依赖，因此公开账号功能不受邮件服务门槛控制。

## 取舍

该方案放弃邮箱所有权证明和自助找回密码，换取不申请域名、不接入邮件供应商且没有系统邮件数据处理和持续费用。管理员人工确认及审计是忘记密码流程的安全补偿。
