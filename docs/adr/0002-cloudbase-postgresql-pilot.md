# ADR-0002：CloudBase PostgreSQL 试点提案（已被负责人决策替代）

本 ADR 原提议在腾讯云 CloudBase 上海 PostgreSQL 上验证大陆访问、持久化和持续成本。负责人于 2026-11-12 明确决定不使用、不验证 CloudBase，也不再考虑该方案；项目运行环境采用已购买的华为云 Flexus L 单机与自管 PostgreSQL。保留本记录作为历史提案，不构成待办或发布门槛。

负责人同时决定不申请域名、不配置 HTTPS，且不再考虑这两项。备案状态仍由负责人确认。未配置 HTTPS 时，任何公开 HTTP 部署只能提供匿名只读内容；登录、注册、账号管理、管理员写操作、收藏及问答入口必须保持关闭。需要管理员维护时通过 SSH 隧道访问本机绑定的管理端点，不通过公网传递凭据或会话。

服务器费用按 Issue 01 记录的实际订单、续费价和按量费用核算，不套用每月人民币 20 元硬门槛。问答及获批后的 LLM Wiki 仍共用人民币 20 元/月应用侧估算预算，详见 Issue 07/09/10。账号采用密码注册、无邮件服务的方案，详见 ADR-0005。
