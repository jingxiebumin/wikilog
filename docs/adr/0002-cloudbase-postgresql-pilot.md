# CloudBase PostgreSQL 试点与费用核算

先在腾讯云 CloudBase 上海 PostgreSQL 上验证大陆访问、持久化数据和持续成本，因为读者主要在中国大陆。该选择只是试点，不设网站与数据库人民币 20 元/月硬门槛；按负责人 2026-11-11 的决定，服务器已购买，Issue 01 需记录实际订单、续费价、按量费用和未计入项，供负责人判断是否接受。问答及获批后的 LLM Wiki 共用人民币 20 元/月应用侧估算预算，该预算与服务器费用分开，详见 Issue 07/09/10。自助账号采用密码注册，邮箱仅作为登录名和人工联系字段；忘记密码由管理员线下确认后通过临时密码处理，详见 ADR-0005。邮件供应商、域名、投递和邮件持续费用不属于本方案依赖。公开账号功能仍受数据库、部署和发布加固验收约束。
