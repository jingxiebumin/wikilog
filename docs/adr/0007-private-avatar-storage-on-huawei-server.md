# ADR-0007：头像存放在华为云服务器私有持久目录

状态：已接受（2026-11-14）

## 背景

用户头像属于仅本人可见的个人信息。项目已购买华为云 Flexus L 服务器；现有 `/srv/wikilog/uploads` 持久目录曾验证可跨容器重建和主机重启保留文件，但目前以只读方式挂载给 Web 容器，真实上传流程尚未验证。对话附件中出现的 `/srv/wikilog/uploads/avatars` 是示例路径，不是已确认的目录选择。

## 决策

- 头像文件存放在已购买的华为云服务器上的私有持久目录，不为头像单独引入对象存储服务。
- 头像目录不直接作为公开静态资源。服务端必须验证会话和资源归属，仅向头像本人提供读取；管理员不能查看读者头像。
- 实际目录路径、容器挂载位置和权限在实施时确定，不将示例路径写成固定配置。
- 头像上传实施前，必须验证应用可写入持久目录、真实图片上传与本人鉴权读取、Web 容器重建/Docker 重启/主机重启后的持久性，以及备份和恢复。
- 图片上传和展示限制按 Issue 11：静态 JPEG、PNG 或 WebP，单张不超过 5 MB；默认使用通用头像图标，用户可上传或更换但不能移除已上传头像。

## 后果

- 头像保存在服务器文件系统并由服务端授权读取；部署须控制目录写权限，禁止匿名直读。
- 验收完成前不启用头像上传功能。验收须记录最终目录和权限、上传/读取测试及持久性、备份恢复结果。
- 该决策只覆盖用户头像，不自动决定文章配图或其他上传文件的存储方案。
