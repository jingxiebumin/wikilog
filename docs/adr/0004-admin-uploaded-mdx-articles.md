# 文章正文由管理员上传 Markdown 维护

状态：已接受；2026-11-17 更新文章管理工作流。

## 决策

管理员使用 Typora 等工具编写 Markdown，并在文章管理对话框上传 `.md` 正文。标题、摘要、封面、分类、标签和文章日期在后台表单单独维护，不从 frontmatter 读取。系统生成的数字文章 ID 用作稳定访问标识，不使用 slug；ID 生成长度和实现方案待定。

新建表单一次提交后创建默认下架的文章。只有下架文章可编辑；编辑时可保留现有 Markdown 文件，重新上传文件仅在表单保存成功后替换当前正文。系统不保留旧文章正文，也不提供文章内容版本的草稿/发布流程。公开状态仅由上架、下架控制。上架、下架及删除需要二次确认；已删除文章从后台列表隐藏且无恢复入口，数据物理清理语义待确认。

文章正文图片暂支持可直接访问的 HTTPS 外链。封面图片表单方式、自托管图片和富文本编辑器留待后续决策。富文本编辑器是未来可能的内容维护方向，不属于当前实施范围。

## 后果

- 文章预览必须通过管理员授权，以新标签打开保存后的文章详情与元数据，并明确标注预览模式；不显示尚未提交的表单内容。
- 文章 ID、标题、分类、标签和日期不依赖 Markdown 文件；摘要可空，为空时从正文第一个有效段落去格式并截取至 120 字。
- 搜索、收藏和问答检索只读取当前上架文章；文章下架时隐藏但保留收藏关系。
- 本决策取代 2026-11-12 以前关于 MDX frontmatter 元数据、文章版本发布、恢复删除文章和配图随文上传的设计及实现记录。
