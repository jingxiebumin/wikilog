元素设计规范

🌤️ 白云

  • 采用简单的圆形组合构成，参考扁平设计风格
  • 不透明度设置在 0.7-0.85 之间，保持天空透视感
  • 3-5 朵白云随机分布，大小约 100-150px
  • 柔和漂浮动画，周期 20-30 秒

🌸 小花

  • 花瓣：橙色 (#ff9800)，直径 8-10px，3-4 瓣
  • 花心：金色 (#ffd700)，直径 4-6px
  • 花茎：绿色 (#7cb342)，高度 25-35px
  • 分布在草地上方，2-4 朵随机位置

🌲 小树

  • 树冠：深绿色 (#558b2f)，简单的圆形或半圆形
  • 树干：棕色 (#8d6e63)，简化的矩形
  • 尺寸：约 50-60px 高
  • 分布在草地中间，1-3 棵点缀

🦆 鹈鹕骑自行车

  • 保留原有的简约卡通风格和蓝色轮廓
  • 身体：浅黄色 (#f5e6d3)，笔画宽度 2px
  • 自行车架：红色 (#c41e3a)，笔画宽度 3px
  • 轮子与其他部分：深灰色 (#2c3e50)
  • 循环动画：从左到右滑动，周期 2 秒，无限循环

💡 实现建议

1. HTML 结构：
在页面底部创建一个 `.theme-footer` 或 `.pelican-scene` 容器，包含背景和动画元素。建议放在 `
` 或专门的装饰区域。
2. 响应式设计：
• 桌面（1024px+）：完整显示，高度 400-500px
• 平板（768px-1023px）：高度 300-350px，调整元素大小
• 手机（<768px）：高度 200-250px，简化元素（移除部分花树）
3. 性能优化：
• 使用 CSS 动画而非 JavaScript，提升性能
• 使用 SVG 实现鹈鹕，支持缩放无失真
• 白云可用 CSS 伪元素创建，减少 DOM 节点
4. 无障碍考虑：
• 为动画元素添加 `role="img"` 和 `aria-label`
• 提供 `prefers-reduced-motion` 媒体查询支持
• 确保背景不影响内容可读性
5. 整合建议：
将此设计作为主页底部装饰，或作为特定页面（如 "关于" 页面）的背景。可以通过 CSS 变量控制显示/隐藏，提升灵活性。

视觉丰富度 低（简单条纹） 高（白云、花树点缀）
动画效果 鹈鹕循环滑动 鹈鹕 + 白云漂浮

整体风格 简约卡通 简约卡通 + 生动自然
