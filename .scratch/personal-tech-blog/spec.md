# 个人技术博客 V1 实施规格

状态：设计已由产品负责人确认。实现阶段遇到外部服务、成本或安全门槛不通过时，保留已完成的公开博客，并按本规格关闭受影响的功能。

本目录是供 AI 按依赖逐步实现的规格和任务。先读根目录 `AGENTS.md`、`GLOSSARY.md`、相关 ADR 和本文件；每轮只实现一个满足依赖条件的 issue，完成其验收标准和验证后再开始下一项。不要把后续阶段或未获准的可选项提前实现。具体第三方服务、配额和部署成本以 issue 01 的验证结果为准，禁止把密钥提交到仓库或发送到浏览器。

## 产品边界

- 新博客与旧私有 RAG 项目、数据环境相互独立，不迁移旧文档、用户、会话或索引。
- 首版采用 TypeScript、Next.js App Router；运行环境采用已购买的华为云 Flexus L 单机和自管 PostgreSQL。负责人已决定不使用、不验证 CloudBase，也不再考虑 CloudBase、域名或 HTTPS。
- 匿名访客可浏览首页、标签、文章详情、搜索、关于/联系页面和知识图谱。首页以分类 Tab 浏览文章；主分类不再占据独立导航入口。所有前台页面在滚动后提供一键回到顶部按钮。
- 登录后通过头像下拉菜单访问个人中心与收藏；管理员另可访问管理员设置。未登录访问个人中心跳转登录页。公开导航与账号入口保持精简。
- 文章原文由管理员在设置区上传 Markdown 文件（`.md`）；标题等配置在后台表单中维护。服务器只保留当前正文，保存重新上传文件后替换正文；本阶段不提供富文本编辑器。
- 负责人决定不申请域名、不做备案、不配置 HTTPS，目标为公网 IP/HTTP。登录凭据与会话会以明文经过 HTTP 传输，可能被链路观察或篡改；负责人接受此风险。公网开放前核对云平台对当前实例及访问方式的适用要求，并完成目标环境、安全和角色验收；不要求 PostgreSQL、文章图片或账号数据的备份恢复，头像目录仍须单独验证备份恢复。
- 公网 IP/HTTP 下允许用户注册/登录；所有 active 登录用户（reader/admin）可添加、查看、移除自己的收藏。问答只对 active admin 开放；管理写操作必须服务端验证身份、角色和限速；需审计的操作按各自 Issue 处理，读者账号管理只记录用户表字段。
- 登录头像菜单显示“个人中心”；管理员专属入口显示“管理员设置”。个人中心和管理员设置统一采用左右布局。管理员设置使用共享左侧菜单和独立二级路由，包含账号管理、文章管理、AI 设置与问答、Wiki 管理、系统设置；系统设置维护文章分类与标签。`/admin` 默认重定向到 `/admin/readers`。匿名用户或 reader 访问 `/admin` 及其任何子路由均显示带首页链接的 404，管理 API 对这两类身份返回 404。
- 个人中心左侧展示头像、昵称、邮箱、手机号、性别、个人介绍、角色和创建日期；右侧标签页分别维护基础信息、邮箱和密码。读者仅能维护自己的个人资料；邮箱作为登录名，修改时要求当前密码，成功后撤销全部会话并跳转登录。账号自助删除页面和 API 暂停。
- 头像采用通用图标作为默认值；仅本人可上传、更换和查看，管理员不能查看或维护读者头像。头像文件存放在已购买的华为云服务器私有持久目录，不作为公开静态资源。实现头像上传前必须验证服务器目录可写、上传/鉴权读取流程、容器与主机重启后持久性以及备份恢复；具体目录实施时确定。
- 账号管理支持管理员仅填写邮箱创建 reader、修改 reader 的昵称/邮箱/手机号/性别、重置密码、软删除和恢复；不支持编辑角色、个人介绍或头像，也不提供启用/停用。账号字段仅保留创建人/时间、最近修改人/时间和删除原因，不记录逐次操作日志。
- 首版不做文章评论、任意文档格式导入、富文本编辑器或读者内容管理。富文本编辑与更便捷的图片托管留作后续讨论。

## 领域规则

### 文章

- 文章使用系统生成的数字 ID 作为稳定访问标识；不使用 slug。ID 作为十进制字符串在应用层传递，具体长度和生成方案待定。
- 新建文章通过对话框填写标题、可选摘要、封面、一个主分类、最多两个标签、文章日期和必传 `.md` 文件；文章日期默认当天。分类和标签由后台系统设置维护。
- 摘要为空时，从 Markdown 正文第一个有效段落去除格式后截取最多 120 字；标题、代码块和图片不用于摘要。
- 新文章保存后默认为下架。只有下架文章可编辑；编辑配置时可保留正文，重新上传的 `.md` 仅在提交保存后替换当前正文。系统不保留旧正文，不提供文章内容版本发布。
- 编辑时显示当前 `.md` 文件名并提供下载；不可删除文件。上架文章可下架或删除；下架文章可编辑、上架或删除。上架、下架和删除均需二次确认；删除后不显示在后台列表且无恢复入口。删除后的数据清理语义待定。
- 预览在新标签页打开，展示已保存正文及分类、标签、日期、阅读时间等信息，标记“预览模式”；右上角按状态提供上架或下架操作。预览不包括尚未保存的修改，状态操作前二次确认。
- 文章正文图片阶段性支持可直接访问的 HTTPS 外链。本机图片、自托管和富文本编辑留待后续讨论；封面图片配置方式待定。
- 主分类是每篇文章唯一的主要归属；标签是可跨分类的补充主题，每篇最多两个。
- 只有负责人本人作为唯一管理员可以新增、编辑、预览、上架、下架和删除文章；读者不能维护文章或模型设置。

### 账号与权限

- 注册表单包含昵称、邮箱、密码、确认密码；确认密码只用于校验，不保存。
- 注册后立即可以登录；邮箱仅作为大小写不敏感的登录名和人工联系字段，不证明邮箱归属，也不发送系统邮件。已登录修改密码要求当前密码、新密码和确认新密码。
- 管理员创建读者及重置密码均使用固定密码 `123456`；新读者首次登录设置昵称并修改密码，已有读者重置后首次登录只需修改密码。管理员无需线下确认身份；重置须二次确认，不填写原因。
- 自助注册默认授予读者权限。管理员只能通过人工初始化；不可通过公开 API 或客户端修改角色。
- 管理员入口只在头像菜单中显示给管理员。文章管理和模型设置的所有服务端操作都必须再次验证管理员权限。
- reader 可管理自己的资料和密码；自助删除暂时停用。个人介绍仅本人可见。普通改密保留当前浏览器会话并撤销其他会话；新读者首次设置昵称和密码后轮换当前会话令牌并继续当前会话。密码重置后的首次登录只需改密。
- 管理员编辑读者邮箱不要求读者密码，修改后撤销该读者全部会话。软删除设置用户表删除标记并保留用户及关联数据；删除原因选填。已删除邮箱可注册新账号；恢复时如邮箱已被未删除账号占用则拒绝恢复，否则恢复账号、清空删除原因且不恢复旧会话。
- 删除会话时一并删除其中的问题、回答和引用记录。对供应商保留数据的说明不得超出已验证的供应商政策。

### 搜索与收藏

- 搜索范围为当前上架文章的标题和正文，支持中文连续子串及不区分大小写的英文关键词；标题命中优先，结果给出命中附近摘要。
- 每位登录用户（reader/admin）对一篇文章最多一条收藏；收藏列表按最近收藏时间排序，用户只能查看和管理自己的关系。
- 文章下架期间在收藏列表中隐藏，但保留关系；文章重新上架后重新显示。

### AI 功能

- 系统 AI 功能当前全部保持关闭，包括管理员问答和 Wiki AI 生成；当前手工文章、Wiki 维护不得触发模型调用。
- AI 生成未来是否提供设置开关、如何由管理员启用、启用后是否只生成待审核草稿，均为待讨论事项。启用路径确认前不得实现可触发供应商调用的入口。
- 未来若重新讨论管理员问答或模型调用，仍需确认功能启用决策并通过 DeepSeek API 专属数据处理政策核验；既有问答细节不代表当前已启用。

### Wiki 页面、知识图谱与 AI

- 管理员在 `/admin/wiki` 手工维护 Wiki 页面。知识图谱只展示已发布页面及管理员维护的页面关系；访客点击节点进入页面详情。
- Wiki 页面包含标题、正文、至少一个有效已发布文章来源和零个或多个相关 Wiki 页面。文章来源和页面关系分别管理；二者均可多对多。页面关系双向生效，孤立页面允许存在；编辑时只能关联已公开页面。
- 新建或编辑在对话框中完成。每个页面最多一份待发布草稿；保存更新后公开页面保持原样，继续编辑覆盖该草稿。预览只检查节点详情、来源和关联列表；发布草稿后才更新公开页面。旧 Wiki 正文版本不保留，仅保留创建/更新审计字段。
- 页面合并先汇总并去重来源文章和页面关系，由管理员整理最终正文并检查草稿；发布后旧地址跳转到保留页面，旧节点及其入边改接到保留页面。
- 当前 AI 功能保持关闭，手工维护 Wiki 是本期能力。AI 生成如何启用及启用后的审核路径仍待讨论；不得自动调用模型或自动生成候选。
- 管理员问答和其他系统 AI 调用在启用决策及数据政策核验完成前保持关闭。

## 发布门槛

- CloudBase、域名、备案和 HTTPS 已由负责人明确排除，不作为项目计划事项或功能门槛。
- Flexus L 与自管 PostgreSQL 的私有单机试点已完成 Issue 01 所列记录。目标为公网 IP/HTTP；公开开放前完成适用的网络、安全和匿名/reader/admin 分角色验收。按 Issue 08，不要求 PostgreSQL、文章图片或账号数据的备份恢复、恢复演练或 RPO/RTO；头像目录仍按本规格及 `docs/SPEC.md` 单独验证备份恢复。注册/登录及 reader/admin 收藏可开放；所有系统 AI 保持关闭，启用另待确认。
- 注册、登录、修改邮箱、修改密码和管理员重置须完成账号、邮箱和 IP 限速及失败处理测试；系统不发送邮件。
- 服务器和基础设施费用记录实际订单、续费价、按量费用和未计入项；问答只记录 token 用量，不设置应用侧费用估算、月预算或费用告警。
- 不以 HTTPS 决定账号、收藏或管理功能开关；HTTP 明文风险由负责人接受。目标环境及服务端授权、限速、审计验收仍未通过时，不得宣称生产功能已开放。AI 问答和 Wiki 生成当前保持关闭。
- AI 功能启用流程和审核要求尚未确认；数据政策核验是未来调用模型的必要条件，但单独通过核验不构成启用授权。
