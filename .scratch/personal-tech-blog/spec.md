# 个人技术博客 V1 实施规格

状态：设计已由产品负责人确认。实现阶段遇到外部服务、成本或安全门槛不通过时，保留已完成的公开博客，并按本规格关闭受影响的功能。

本目录是供 AI 按依赖逐步实现的规格和任务。先读根目录 `AGENTS.md`、`GLOSSARY.md`、相关 ADR 和本文件；每轮只实现一个满足依赖条件的 issue，完成其验收标准和验证后再开始下一项。不要把后续阶段或未获准的可选项提前实现。具体第三方服务、配额和部署成本以 issue 01、03 的验证结果为准，禁止把密钥提交到仓库或发送到浏览器。

## 产品边界

- 新博客与旧私有 RAG 项目、数据环境相互独立，不迁移旧文档、用户、会话或索引。
- 首版采用 TypeScript、Next.js App Router；CloudBase 上海 PostgreSQL 是试点，不是永久供应商承诺。
- 匿名访客可浏览首页、分类、标签、文章详情、搜索和关于/联系页面。公开文章、主分类和标签无需登录。
- 登录后通过头像下拉菜单访问账号设置、收藏列表和问答会话；管理员在同一菜单看到博客设置入口。公开导航与账号入口保持精简。
- 文章原文由管理员在设置区上传 MDX 和配图。服务端保存的文章版本及元数据是权威内容；文章不是从仓库部署时自动生成的。
- 账号功能依赖公开环境的邮件、数据库和持续成本验证。门槛失败时保持公开博客可用，关闭注册、登录、收藏和问答。
- 登录头像下拉菜单集中放置账号设置、收藏、问答会话和（仅管理员可见的）博客设置入口。管理员在简洁的设置区维护文章并管理 AI 模型；不要构建复杂仪表盘。
- 首版不做文章评论、公开 Wiki、任意文档格式导入、富文本编辑器或读者内容管理。

## 领域规则

### 文章

- 每个上传的 MDX 文件在 frontmatter 中声明稳定 slug、标题、发布时间、唯一主分类、零个或多个标签和摘要；发布状态由后台工作流管理，上传总是先生成草稿。
- 主分类使用受控集合；标签是跨主分类的补充主题。
- 首版主分类由受控配置维护，不增加单独的分类管理页面。
- 上传先生成草稿；管理员可预览，只有显式发布才公开。
- 上传已有 slug 的新版本时，已发布版本继续服务，直至新版本显式发布。
- 下架或删除采用可恢复状态；草稿和下架文章不出现在公开页、搜索、收藏列表或问答检索结果中。重新发布后恢复原收藏关系。
- 配图随文章上传并保留相对引用；未上传的外链图只允许 HTTPS。
- 上传的 MDX 不得执行导入、脚本或任意组件代码；只支持明确列出的安全语法和受控组件，并防止 HTML/链接注入。

### 账号与权限

- 注册表单包含昵称、邮箱、密码、确认密码；确认密码只用于校验，不保存。
- 注册完成后须点击一次性邮件验证链接才能登录。忘记密码通过一次性邮件重置链接；已登录修改密码要求旧密码、新密码和确认新密码。首版不使用邮箱验证码。
- 自助注册默认授予读者权限。管理员只能通过人工初始化；不可通过公开 API 或客户端修改角色。
- 管理员入口只在头像菜单中显示给管理员。文章管理和模型设置的所有服务端操作都必须再次验证管理员权限。
- 读者可管理自己的资料、修改密码、查看和删除自己的问答会话及删除账号；不得访问其他账号数据。
- 删除会话时一并删除其中的问题、回答和引用记录。删除账号时删除该读者的收藏、问答会话和其他本地个人数据；删除前需再次验证身份。对供应商保留数据的说明不得超出已验证的供应商政策。

### 搜索与收藏

- 搜索范围为当前已发布版本的标题和正文，支持中文连续子串及不区分大小写的英文关键词；标题命中优先，结果给出命中附近摘要。
- 每位读者对一篇文章最多一条收藏；收藏列表按最近收藏时间排序。
- 文章下架期间在收藏列表中隐藏，但保留关系，文章再次发布后重新显示。

### AI 问答与费用

- 首版仅接 DeepSeek；管理员只能选择服务端预先配置和验证过的 DeepSeek 文本模型。只有一个可用模型时隐藏切换控件。API Key 和私密模型配置不得暴露到客户端。
- 读者可从文章页或问答页提问；检索范围为全部已发布文章。每个事实性回答必须附一篇或多篇可校验的原文引用并链接到公开文章；证据不足时明确拒答，不用模型常识补造结论。
- 回答目标上限约 800 个中文字。记录输入/输出 token、所选模型和费用估算。
- 每名读者每日最多 5 个已提交到模型的请求，按 `Asia/Shanghai` 自然日重置。通过输入校验并提交模型即计数，即使超时仍计数；提交模型前失败不计数。防止并发绕过配额。
- 问答和（如后续批准采用）LLM Wiki 更新共享每个 `Asia/Shanghai` 自然月人民币 20 元应用侧估算预算。调用前必须原子预留；并发下预留余额不可超限。调用后按实际 token 用量调整估算记录，预估余额不足则拒绝调用。计费月开始时恢复。
- 预算使用达到 80% 时在管理员设置区提示；若实现主动通知，须由负责人明确配置通知方式。实际供应商账单仍需对账；该应用预算不是供应商的计费硬限额。
- 开放问答前须验证供应商数据处理政策，尤其是读者问题与回答不用于模型训练。

### LLM Wiki 条件

- 先建立固定代表性题集，包含可回答问题、跨文章问题和证据不足问题；在同一题集上比较直接检索文章原文和 LLM Wiki 两种方案。
- 采用门槛：事实正确性和引用有效性均不低于原文方案；纳入 Wiki 更新消耗后仍符合共同月预算；结果由负责人审阅并明确批准。
- 未通过或未获批准时只保留原文问答。通过后才实现 Wiki 更新、检索和回退；Wiki 仅供内部问答辅助，文章原文保持权威。文章发布新版本后触发更新，失败时继续使用最近一次成功知识层。

## 发布门槛

- TypeScript/Next.js 部署、CloudBase PostgreSQL、配图持久存储在目标环境验证可用，记录大陆访问和试用结束后的持续费用。
- 注册邮件验证链接与忘记密码链接须在公开环境完成端到端投递和使用测试；邮件服务须有可用免费额度，且邮件/IP 频率限制和失败处理已验证。
- 网站与数据库月度成本目标为人民币 20 元以内；若超过，须先记录明确的成本依据。
- 不满足邮件或成本门槛时，只发布公开博客，不开放读者账号、收藏或问答。
- 问答开放前完成 DeepSeek 数据政策、token 计量、预算预留、日配额、错误处理和来源校验验证。
