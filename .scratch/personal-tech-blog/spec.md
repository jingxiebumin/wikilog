# 个人技术博客 V1 实施规格

状态：设计已由产品负责人确认。实现阶段遇到外部服务、成本或安全门槛不通过时，保留已完成的公开博客，并按本规格关闭受影响的功能。

本目录是供 AI 按依赖逐步实现的规格和任务。先读根目录 `AGENTS.md`、`GLOSSARY.md`、相关 ADR 和本文件；每轮只实现一个满足依赖条件的 issue，完成其验收标准和验证后再开始下一项。不要把后续阶段或未获准的可选项提前实现。具体第三方服务、配额和部署成本以 issue 01 的验证结果为准，禁止把密钥提交到仓库或发送到浏览器。

## 产品边界

- 新博客与旧私有 RAG 项目、数据环境相互独立，不迁移旧文档、用户、会话或索引。
- 首版采用 TypeScript、Next.js App Router；运行环境采用已购买的华为云 Flexus L 单机和自管 PostgreSQL。负责人已决定不使用、不验证 CloudBase，也不再考虑 CloudBase、域名或 HTTPS。
- 匿名访客可浏览首页、分类、标签、文章详情、搜索和关于/联系页面。公开文章、主分类和标签无需登录。
- 登录后通过头像下拉菜单访问个人中心与收藏；管理员另可访问管理员设置。未登录访问个人中心跳转登录页。公开导航与账号入口保持精简。
- 文章原文由管理员在设置区上传 MDX 和配图。服务端保存的文章版本及元数据是权威内容；文章不是从仓库部署时自动生成的。
- 负责人决定不申请域名、不做备案、不配置 HTTPS，目标为公网 IP/HTTP。登录凭据与会话会以明文经过 HTTP 传输，可能被链路观察或篡改；负责人接受此风险。公网开放前核对云平台对当前实例及访问方式的适用要求，并完成目标环境、安全和角色验收；不要求 PostgreSQL、文章图片或账号数据的备份恢复，头像目录仍须单独验证备份恢复。
- 公网 IP/HTTP 下允许用户注册/登录；所有 active 登录用户（reader/admin）可添加、查看、移除自己的收藏。问答只对 active admin 开放；管理写操作必须服务端验证身份、角色和限速；需审计的操作按各自 Issue 处理，读者账号管理只记录用户表字段。
- 登录头像菜单显示“个人中心”；管理员专属入口显示“管理员设置”。个人中心和管理员设置统一采用左右布局。管理员设置使用共享左侧菜单和独立二级路由，菜单顺序为账号管理、文章管理、AI 设置与问答、Wiki 管理；`/admin` 默认重定向到 `/admin/readers`。匿名用户或 reader 访问 `/admin` 及其任何子路由均显示带首页链接的 404，管理 API 对这两类身份返回 404。
- 个人中心左侧展示头像、昵称、邮箱、手机号、性别、个人介绍、角色和创建日期；右侧标签页分别维护基础信息、邮箱和密码。读者仅能维护自己的个人资料；邮箱作为登录名，修改时要求当前密码，成功后撤销全部会话并跳转登录。账号自助删除页面和 API 暂停。
- 头像采用通用图标作为默认值；仅本人可上传、更换和查看，管理员不能查看或维护读者头像。头像文件存放在已购买的华为云服务器私有持久目录，不作为公开静态资源。实现头像上传前必须验证服务器目录可写、上传/鉴权读取流程、容器与主机重启后持久性以及备份恢复；具体目录实施时确定。
- 账号管理支持管理员仅填写邮箱创建 reader、修改 reader 的昵称/邮箱/手机号/性别、重置密码、软删除和恢复；不支持编辑角色、个人介绍或头像，也不提供启用/停用。账号字段仅保留创建人/时间、最近修改人/时间和删除原因，不记录逐次操作日志。
- 首版不做文章评论、公开 Wiki、任意文档格式导入、富文本编辑器或读者内容管理。

## 领域规则

### 文章

- 每个上传的 MDX 文件在 frontmatter 中声明稳定 slug、标题、发布时间、唯一主分类、零个或多个标签和摘要；发布状态由后台工作流管理，上传总是先生成草稿。
- 主分类使用受控集合；标签是跨主分类的补充主题。
- 首版主分类由受控配置维护，不增加单独的分类管理页面。
- 上传先生成草稿；管理员可预览，只有显式发布才公开。
- 上传已有 slug 的新版本时，已发布版本继续服务，直至新版本显式发布。
- 文章实体区分正常、下架和删除；下架与删除都是可恢复的隐藏状态，V1 不提供文章永久删除。文章版本按 `draft -> published -> archived` 流转；发布新版本时在事务中切换 `current_published_version_id`，旧当前版本归档。草稿、下架和删除文章不出现在公开页、搜索、收藏列表或问答检索结果中；重新发布或恢复后保留原收藏关系。
- 只有负责人本人作为唯一管理员可以上传、预览、发布、下架、删除和恢复文章；读者不能维护文章或模型设置。
- 配图随文章上传并保留相对引用；未上传的外链图只允许 HTTPS。
- 上传的 MDX 不得执行导入、脚本或任意组件代码；只支持明确列出的安全语法和受控组件，并防止 HTML/链接注入。

### 账号与权限

- 注册表单包含昵称、邮箱、密码、确认密码；确认密码只用于校验，不保存。
- 注册后立即可以登录；邮箱仅作为大小写不敏感的登录名和人工联系字段，不证明邮箱归属，也不发送系统邮件。已登录修改密码要求当前密码、新密码和确认新密码。
- 管理员创建读者及重置密码均使用固定密码 `123456`；新读者首次登录设置昵称并修改密码，已有读者重置后首次登录只需修改密码。管理员无需线下确认身份；重置须二次确认，不填写原因。
- 自助注册默认授予读者权限。管理员只能通过人工初始化；不可通过公开 API 或客户端修改角色。
- 管理员入口只在头像菜单中显示给管理员。文章管理和模型设置的所有服务端操作都必须再次验证管理员权限。
- reader 可管理自己的资料和密码；自助删除暂时停用。个人介绍仅本人可见。普通改密保留当前浏览器会话并撤销其他会话；新读者首次设置昵称和密码后轮换当前会话令牌并继续当前会话。密码重置后的首次登录只需改密。
- 管理员编辑读者邮箱不要求读者密码，修改后撤销该读者全部会话。软删除设置用户表删除标记并保留用户及关联数据；删除原因选填。已删除邮箱可注册新账号；恢复时如邮箱已被未删除账号占用则拒绝恢复，否则恢复账号、清空删除原因且不恢复旧会话。
- 删除会话时一并删除其中的问题、回答和引用记录。对供应商保留数据的说明不得超出已验证的供应商政策。

### 搜索与收藏

- 搜索范围为当前已发布版本的标题和正文，支持中文连续子串及不区分大小写的英文关键词；标题命中优先，结果给出命中附近摘要。
- 每位登录用户（reader/admin）对一篇文章最多一条收藏；收藏列表按最近收藏时间排序，用户只能查看和管理自己的关系。
- 文章下架期间在收藏列表中隐藏，但保留关系，文章再次发布后重新显示。

### AI 问答与用量

- 首版仅接 DeepSeek；管理员只能选择服务端预先配置和验证过的 DeepSeek 文本模型。只有一个可用模型时隐藏切换控件。API Key 和私密模型配置不得暴露到客户端。
- 仅管理员可从文章页或问答页提问；reader 和匿名用户不得调用问答 API。问答先检索已发布 Wiki 页面，无适用页面时只检索少量当前已发布文章原文片段，不向模型发送全部文章。每个事实性回答必须附一篇或多篇可校验的原文版本引用，引用保存文章版本、原文片段和可验证地址；证据不足时明确拒答，不用模型常识补造结论。
- 回答目标上限约 800 个中文字。记录输入/输出 token 和所选模型，不换算费用。
- 每名管理员每日最多 5 次成功回答，按 `Asia/Shanghai` 自然日重置；证据不足拒答、供应商错误和超时不计次。请求超时为 60 秒，不自动重试；管理员主动重试视为新请求。不另设每分钟限流或每日供应商提交调用上限，并发不能绕过成功回答配额。
- DeepSeek API 专属数据处理政策核验通过前，问答功能保持关闭；政策不明确或核验失败时继续关闭。核验通过后才可按管理员权限开放。

### Wiki 页面与管理员问答

- Wiki 是按主题组织的公开知识页面。管理员在 `/admin/wiki` 手动创建、编辑、合并页面并审核 AI 候选内容和主题关系；访客/读者通过独立入口中的可点击知识图谱查看已发布页面。现有文章首页保持不变。
- 初次启用时根据全部当前已发布文章生成候选页面；文章发布或新版本发布后异步生成受影响页面的候选更新，不阻塞文章发布。按页面审核，失败或待审均保留当前已发布页面；页面失去全部有效来源后从公开图谱和问答检索隐藏。
- 问答先检索已发布 Wiki 页面；没有适用结果时仅检索少量相关文章原文片段兜底，不得把全部文章发送给模型。事实依据与引用始终回到具体已发布文章版本；证据不足时拒答。
- 首版用 PostgreSQL 搜索，不引入向量数据库；上游 `llm_wiki` 仅作参考，不作为运行依赖。
- Issue 09 原文/Wiki 比较评估维持 `wontfix`，不阻塞实现；Issue 10 获准实施并标记 `ready-for-agent`。

## 发布门槛

- CloudBase、域名、备案和 HTTPS 已由负责人明确排除，不作为项目计划事项或功能门槛。
- Flexus L 与自管 PostgreSQL 的私有单机试点已完成 Issue 01 所列记录。目标为公网 IP/HTTP；公开开放前完成适用的网络、安全和匿名/reader/admin 分角色验收。按 Issue 08，不要求 PostgreSQL、文章图片或账号数据的备份恢复、恢复演练或 RPO/RTO；头像目录仍按本规格及 `docs/SPEC.md` 单独验证备份恢复。注册/登录及 reader/admin 收藏可开放；问答仅 admin 可用。
- 注册、登录、修改邮箱、修改密码和管理员重置须完成账号、邮箱和 IP 限速及失败处理测试；系统不发送邮件。
- 服务器和基础设施费用记录实际订单、续费价、按量费用和未计入项；问答只记录 token 用量，不设置应用侧费用估算、月预算或费用告警。
- 不以 HTTPS 决定账号、收藏或管理功能开关；HTTP 明文风险由负责人接受。目标环境及服务端授权、限速、审计验收仍未通过时，不得宣称生产功能已开放。问答仅 admin 可用，并须通过 DeepSeek API 专属数据政策核验。
- 问答开放前完成 DeepSeek API 专属数据政策核验、token 用量记录、成功回答日配额、错误处理和来源校验验证；政策不明确或核验失败时保持关闭。
