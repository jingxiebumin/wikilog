# Issue 04: 实现读者账号与管理员权限

Status: ready-for-agent
Type: task
Blocked by: 02

## 目标

实现邮箱密码账号、自助读者角色、临时密码找回和受保护管理员入口。邮箱只作为登录名和人工联系字段；系统不发送邮件。

## 范围

- 注册昵称、邮箱、密码、确认密码；服务端验证并保证邮箱唯一，确认密码不入库。
- 登录/登出、注册后立即启用读者账号、登录后通过当前密码修改邮箱和密码。
- 忘记密码由管理员线下确认身份后生成一次性临时密码；临时密码只显示一次，首次登录必须修改。
- 对账号、邮箱和来源 IP 限速；错误响应避免枚举已注册邮箱。
- 公开注册永远只产生读者角色。通过受控的一次性人工初始化方式建立管理员；没有自助提权接口。
- 头像菜单中按服务端会话角色显示设置入口；设置操作每次服务端授权检查。
- 头像菜单集中账号设置、收藏、问答会话入口；管理员可见的设置区入口通向文章与 AI 模型管理，不增加复杂后台仪表盘。
- 受保护的管理员入口支持人工创建/禁用读者账号和重置密码；公开注册永远只产生 reader。管理员重置记录操作者、目标账号、时间、原因和结果，不记录临时密码。
- 账号删除的重新验证和确认流程；删除账号时级联删除本地收藏、问答和个人数据。

## 验收标准

- 注册后账号立即可以登录和使用已开放的读者功能；邮箱不代表已验证身份，系统不发送注册、登录、改密或重置邮件。
- 密码只使用成熟密码哈希方案保存；修改密码要求当前密码正确。
- 未登录用户不能访问读者页面，读者不能访问设置/API，伪造客户端角色也不能提升权限。
- 账号、邮箱和 IP 限速阈值有安全理由、有测试且可配置；临时密码只可使用一次并在首次登录后失效；响应不泄露邮箱是否存在。
- 账号删除只影响当前用户关联数据，且操作需要重新验证身份。
- 管理员重置前必须完成线下身份确认并留下审计记录；没有自助找回密码承诺。
- 数据库、部署或发布加固门槛未通过时，账号相关入口关闭，公开博客不受影响。
