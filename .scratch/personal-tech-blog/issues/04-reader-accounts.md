# Issue 04: 实现读者账号与管理员权限

Status: ready-for-human
Type: task
Blocked by: 02

## 目标

实现邮箱密码账号、自助读者角色、临时密码找回和受保护管理员入口。邮箱只作为登录名和人工联系字段；系统不发送邮件。

## 范围

- 注册昵称、邮箱、密码、确认密码；服务端验证并保证邮箱唯一，确认密码不入库。
- 登录/登出、注册后立即启用读者账号、登录后通过当前密码修改邮箱和密码。
- 忘记密码由管理员线下确认身份后生成一次性临时密码；临时密码只显示一次，首次登录必须修改。
- 对账号、邮箱和来源 IP 限速；错误响应避免枚举已注册邮箱。
- 公开注册永远只产生读者角色。通过受控的一次性人工初始化方式建立管理员；没有自助提权接口。
- 头像菜单中按服务端会话角色显示设置入口；设置操作每次服务端授权检查。
- 头像菜单集中账号设置、收藏、问答会话入口；管理员可见的设置区入口通向文章与 AI 模型管理，不增加复杂后台仪表盘。
- 受保护的管理员入口支持人工创建/禁用读者账号和重置密码；公开注册永远只产生 reader。管理员重置记录操作者、目标账号、时间、原因和结果，不记录临时密码。
- 账号删除的重新验证和确认流程；删除账号时级联删除本地收藏、问答和个人数据。

## 验收标准

- 注册后账号立即可以登录和使用已开放的读者功能；邮箱不代表已验证身份，系统不发送注册、登录、改密或重置邮件。
- 密码只使用成熟密码哈希方案保存；修改密码要求当前密码正确。
- 未登录用户不能访问读者页面，读者不能访问设置/API，伪造客户端角色也不能提升权限。
- 账号、邮箱和 IP 限速阈值有安全理由、有测试且可配置；临时密码只可使用一次并在首次登录后失效；响应不泄露邮箱是否存在。
- 账号删除只影响当前用户关联数据，且操作需要重新验证身份。
- 管理员重置前必须完成线下身份确认并留下审计记录；没有自助找回密码承诺。
- 数据库、部署或发布加固门槛未通过时，账号相关入口关闭，公开博客不受影响。

实现与验收对应关系：

- 注册校验昵称、邮箱、密码和确认密码；邮箱在数据库唯一索引及服务端规范化下大小写不敏感，注册立即创建 `active/reader` 账号并建立会话，确认密码不入库。
- 登录、退出、当前密码修改邮箱/密码和账号删除均有服务端 Route Handler；密码使用 Node `scrypt` 带盐哈希，会话 Cookie 为 HttpOnly、SameSite=Lax，数据库只保存会话 token 哈希。
- 管理员初始化只通过 `npm run admin:init`，使用 `ADMIN_EMAIL`、`ADMIN_DISPLAY_NAME`、`ADMIN_PASSWORD` 一次性人工初始化并以事务锁防止并发重复；公开注册和管理员创建都不能授予 `admin` 角色。
- 管理员创建/禁用读者及重置密码入口都重新检查服务端会话角色。重置要求 `identityConfirmed=true` 和非空原因，撤销目标旧会话，生成一次性临时密码并设置首次改密标志；审计保存操作者、目标邮箱快照、原因、时间、结果和使用时间，不保存临时密码。
- 登录和注册按账号/IP 使用数据库原子限速；管理员重置按目标账号/IP 限速。阈值默认注册账号 3 次、注册 IP 8 次、登录账号 8 次、登录 IP 20 次、管理员重置账号 5 次、管理员重置 IP 10 次，窗口均为 15 分钟，可用环境变量覆盖。失败登录统一返回通用错误，不枚举邮箱。
- `0003_reader_accounts.sql` 将旧 `pending` 行按是否已有密码迁移为 `active/disabled`，删除 `email_verified_at`，新增 `password_reset_required`、会话、重置审计和限速表。删除读者账号需要当前密码及 `DELETE` 确认，并硬删除以触发账号关联数据级联清理；管理员账号不可通过读者删除流程删除，重置审计保留目标邮箱快照。
- `AUTH_ENABLED=false` 或未配置数据库时，账号入口、会话和受保护操作关闭；公开博客路由仍可匿名访问。人工初始化脚本可在数据库已迁移后独立执行，不受公开入口开关影响。

2026-11-11：根据代码、迁移、测试与负责人确认补充领域规则。下列代码行为已有证据；标为“待实现”的账号管理细节不代表当前已经支持。

- **业务目标与领域规则**：维护 `读者账号`、`管理员`、`临时密码` 和 `问答会话` 所需身份。公开注册只能创建 active reader；管理员由 `npm run admin:init` 一次性初始化。邮箱是大小写不敏感登录名与人工联系字段，不表示已验证。负责人本人是唯一管理员；读者及匿名用户不能发布或修改文章。
- **状态流转**：账号为 `active` 或 `disabled`；成功注册为 active，管理员禁用转为 disabled 并撤销现有会话，禁用账号不能登录；待实现管理员重新启用后转回 active，旧会话不恢复。管理员重置密码后设置 `passwordResetRequired`，目标账号须登录并修改密码后清除此标志；成功改密撤销该用户所有会话。读者删除自己的账号为硬删除，本地外键级联清理其会话和未来新增的个人数据；密码重置审计保留邮箱快照。
- **权限边界**：每个页面和写路由从服务端会话判定角色/状态；客户端角色不可信。管理员可人工创建、禁用、重新启用和重置 reader；管理员不能由公开接口创建或提权，也不能通过管理员界面删除 reader。读者可删除自己的账号，管理员账号不能使用读者自删流程。
- **正常流程**：读者注册后立即登录；登录时创建 30 天 HttpOnly 会话；修改邮箱/密码需当前密码；忘记密码由管理员线下确认身份并记录原因后生成只展示一次的临时密码，首次登录改密；读者删除账号需当前密码和 `DELETE` 确认。
- **异常与边界**：重复邮箱和错误凭据不暴露账号是否存在；账号、邮箱与 IP 限速；禁用、过期或撤销会话不能通过认证。数据库未配置或 `AUTH_ENABLED` 非 `true` 时账号入口关闭，匿名公开博客保持可用。管理员线下身份确认是人工流程，服务端只接收确认标记并审计。
