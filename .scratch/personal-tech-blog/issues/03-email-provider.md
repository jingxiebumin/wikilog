# Issue 03: 验证邮箱链接服务

Status: wontfix
Type: research

## 目标

原目标是选定可用于注册验证和忘记密码的一次性邮件链接服务。负责人已决定不申请域名、不接入 Resend/Brevo 等邮件供应商，注册和密码恢复改用不发送系统邮件的账号方案，因此本 issue 不再执行。

## 验收标准

本 issue 原验收标准针对邮件供应商，因负责人决定不接入邮件服务而不适用。账号安全要求已转入 Issue 04：密码哈希、会话保护、账号/邮箱/IP 限速、管理员临时密码、首次登录强制改密和审计。

## Comments

2026-11-07：负责人决定不申请发送域名，也不接入 Resend、Brevo 等邮件供应商。读者注册后立即可登录；邮箱仅作为大小写不敏感的登录名和人工联系字段，不证明邮箱归属；注册、登录、修改邮箱、修改密码和管理员重置均不发送系统邮件。忘记密码由管理员线下确认身份后生成一次性临时密码，临时密码只显示一次，首次登录必须修改，操作记录审计信息但不记录临时密码。Issue 04 不再依赖本 issue，账号安全改由密码哈希、会话保护、账号/邮箱/IP 限速、管理员权限和审计保证。公开博客不受影响。

此前的 Resend/Brevo 资料仅是历史调研，不代表推荐或已选定供应商，也不构成投递、免费额度、持续费用或数据处理验收证据。`lib/email/**` 已移除，仓库不保留邮件凭据、adapter 或发送入口。
