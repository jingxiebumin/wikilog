# Issue 06: 实现收藏与读者数据生命周期

Status: ready-for-agent
Type: task
Blocked by: 04, 05

## 目标

实现读者收藏列表，并在账号删除时清理该用户的收藏数据。

## 验收标准

- 每位读者对每篇文章最多有一条收藏；并发重复请求不会生成重复数据。
- 收藏列表按最近收藏时间倒序；草稿/下架文章隐藏，重新发布后原收藏恢复。
- 读者只能列出、创建和删除自己的收藏；后端验证所有权。
- 账号删除时删除该账号的收藏数据；后续功能新增个人数据时须扩展删除级联。
- 覆盖重复收藏、他人数据访问、文章下架/重发和账号删除收藏清理的测试。
