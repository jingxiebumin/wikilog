# Issue 07: 实现基于文章原文的管理员问答

Status: ready-for-agent
Type: task
Blocked by: 01, 02, 04, 05

## 目标

接入 DeepSeek，仅供管理员基于已发布文章提问；可靠保存管理员会话、来源和 token 用量。问答启用前必须核实 DeepSeek API 专属数据处理政策；不得把未核实的训练或保留政策写成事实。

## 范围

- admin 从文章页或问答页提问；reader 和匿名用户不能使用问答入口或 API。检索全部已发布文章并返回一篇或多篇有效来源链接。
- 服务端把可引用文章版本绑定到检索结果并校验模型返回的来源标识；不得直接信任模型生成的任意 URL 或引用。
- 明确提示证据不足并拒答；不能把模型自身知识伪装成文章依据。
- 单个问题最多 2,000 个字符，超出时在调用模型前拒绝；回答目标不超过约 800 个中文字。记录模型、输入/输出 token 和文章版本，不换算费用。
- 管理设置中从服务端预先配置的 DeepSeek 文本模型选择；只配置一个时不显示切换控件。模型 API 凭据始终服务端持有。
- 管理员问答会话列表/详情和删除；按管理员所有权隔离。
- 删除会话时一并删除会话中的问题、回答和引用；删除管理员账号时清理全部本地问答数据。
- 每名管理员每日最多 5 次成功回答，按 `Asia/Shanghai` 自然日计算；超时、供应商错误和证据不足拒答不计次。仅成功回答占用配额，并发不能绕过上限；不另设每分钟限流或已提交调用总上限。
- 模型调用超时为 60 秒，不自动重试；管理员主动重试会创建新的调用。实施调用前的输入限制、用户可理解的失败响应和日志脱敏。

## 验收标准

- 引用指向回答所用的已发布文章版本；草稿、下架文章和无关来源不能被引用。
- 对可回答和证据不足场景检查回答证据、引用和拒答行为。
- 并发每日配额测试证明每天最多 5 个成功回答；超时、供应商错误和证据不足拒答不占配额。
- 问题超过 2,000 个字符时不调用供应商；供应商调用在 60 秒超时且不自动重试。
- API Key 不在前端包、网络响应、日志或错误中出现；问答 API、会话和模型选择仅允许管理员。
- 会话删除清除问题、回答和引用；账号删除会清理全部本地问答数据。
- DeepSeek API 专属数据处理政策已核实并符合负责人接受的使用条件；政策不明确或核验失败时问答保持关闭。

## Comments

2026-11-11：根据负责人确认补齐问答状态、计数和预算规则。当前仓库没有问答表、模块、模型适配器或功能测试；以下是待实现规格，DeepSeek API 数据政策和价格仍须验证。

- **业务目标与领域规则**：管理员围绕 `问答会话` 提交问题；reader 和匿名用户不可使用问答。回答只以当前已发布文章版本为证据，模型不得提供任意 URL。`问答引用` 必须保留具体版本 ID、片段/位置和可验证版本地址，使后续文章更新不改变历史引用含义。
- **状态流转**：有效问题建立问答消息，处理状态依次为 `processing` 后终态 `succeeded`、`refused`、`failed` 或 `timed_out`；只有成功事实回答保留有效引用，拒答/失败/超时不得伪造引用。空会话不单独保存；会话内问题按提交顺序处理。删除会话级联消息和引用，账号删除级联其全部问答数据。
- **权限边界**：问答、会话读取和删除要求 active admin 会话并校验会话所有权；reader/匿名用户请求拒绝。API Key、模型配置、提示内部信息只在服务端。只允许使用已验证的 DeepSeek 文本模型 allowlist。
- **正常流程**：验证 active admin、问题及会话归属，检索当前公开原文，提交模型后校验来源 ID、生成可验证引用并记录模型和 token 用量；问题最多 2,000 个字符，回答目标不超过约 800 个中文字。
- **异常与边界**：提交供应商前的输入/权限/检索失败不计配额；只有成功事实回答占用每日配额。供应商错误、超时和证据不足拒答不计次。60 秒超时，不自动重试；管理员主动重试作为新调用。无每分钟限流或每日供应商提交总上限。相同会话并发请求按提交顺序处理。
- **依赖**：依赖 Issue 01 目标环境、Issue 02 公开内容查询、Issue 04 读者身份、Issue 05 版本/发布状态；Issue 08 验收安全和功能开关。Issue 09 已取消，不再是原文问答基线的实施依赖。
- **可验证验收**：测试成功回答每日原子配额上限；拒答、供应商错误和超时不占配额；校验 2,000 字符边界和 60 秒超时；引用可验证到当时版本；越权隔离和删除级联；确认密钥不进入 bundle/响应/日志；DeepSeek API 数据政策通过核验后才开放。
- **待验证**：DeepSeek API 专属数据处理政策需在启用问答前按供应商当前资料核验。官方价目会变化，实施时复核；截至 2026-11-15 官方 [`deepseek-flash` 价目](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)为缓存命中输入 ¥0.02/¥0.04、未命中输入 ¥1/¥2、输出 ¥4/¥8 每百万 token（空闲/高峰）。项目不按该价格估算费用或执行月预算。
