# Issue 07: 实现基于文章原文的问答与预算控制

Status: ready-for-agent
Type: task
Blocked by: 01, 02, 04, 05

## 目标

接入 DeepSeek，基于已发布文章回答读者问题；可靠保存会话、来源、用量和预算预留。

## 范围

- 从文章页或问答页提问；检索全部已发布文章并返回一篇或多篇有效来源链接。
- 服务端把可引用文章版本绑定到检索结果并校验模型返回的来源标识；不得直接信任模型生成的任意 URL 或引用。
- 明确提示证据不足并拒答；不能把模型自身知识伪装成文章依据。
- 回答目标不超过约 800 个中文字；记录模型、输入/输出 token、文章版本和估算成本。
- 管理设置中从服务端预先配置的 DeepSeek 文本模型选择；只配置一个时不显示切换控件。模型 API 凭据始终服务端持有。
- 问答会话列表/详情和删除；按所有权隔离。
- 删除会话时一并删除会话中的问题、回答和引用；删除账号时清理全部本地问答数据。
- 每人每日最多 5 次，按 `Asia/Shanghai` 自然日计算。有效并提交模型时计数，模型超时仍计数；提交前失败不计数。并发不能绕过上限。
- 问答与未来 Wiki 更新共享月预算：调用前事务性原子预留，结束后用实际 token 估算结算；按 `Asia/Shanghai` 自然月人民币 20 元应用侧预算拒绝余额不足的请求；80% 显示管理员提示。
- 实施调用前的输入限制、模型超时、用户可理解的失败响应和日志脱敏。

## 验收标准

- 引用指向回答所用的已发布文章版本；草稿、下架文章和无关来源不能被引用。
- 对固定可回答与不可回答样例检查回答证据、引用和拒答行为；不通过时不开放问答。
- 并发预算预留和并发每日配额测试证明不会超发；超时请求仍正确计数。
- 跨月未完成调用仍结算到发起时预留的月份，不得通过月度重置遗失预留。
- API Key 不在前端包、网络响应、日志或错误中出现；管理员权限保护模型选择。
- 会话删除清除问题、回答和引用；账号删除会清理全部本地问答数据。
- DeepSeek 数据处理/不用于训练政策已验证；验证失败时问答保持关闭。

## Comments

2026-11-11：根据负责人确认补齐问答状态、计数和预算规则。当前仓库没有问答表、模块、模型适配器或功能测试；以下是待实现规格，DeepSeek 数据政策/价格仍须实测验证。

- **业务目标与领域规则**：读者围绕 `问答会话` 提交问题；回答只以当前已发布文章版本为证据，模型不得提供任意 URL。`问答引用` 必须保留具体版本 ID、片段/位置和可验证版本地址，使后续文章更新不改变历史引用含义。
- **状态流转**：有效问题建立问答消息，处理状态依次为 `processing` 后终态 `succeeded`、`refused`、`failed` 或 `timed_out`；只有成功事实回答保留有效引用，拒答/失败/超时不得伪造引用。空会话不单独保存；会话内问题按提交顺序处理。删除会话级联消息和引用，账号删除级联其全部问答数据。
- **权限边界**：问答、会话读取和删除要求 active reader 会话并校验会话所有权；管理员不能读取读者私有会话。API Key、模型配置、提示内部信息只在服务端。只允许使用已验证的 DeepSeek 文本模型 allowlist。
- **正常流程**：校验问题及归属、检索当前公开原文、原子占用每日配额并预留预算，再提交模型；校验模型来源 ID、生成可验证引用、记录模型/token/费用，答案目标不超过约 800 个中文字。
- **异常与边界**：提交供应商前的输入/权限/检索/预算失败不计配额并释放已做预留；提交供应商后成功、拒答、供应商错误和超时都计每日额度，超时保留状态并按可得 usage 或保守估算结算；结算和释放幂等。预算不足不调用。跨月请求归属于提交时的 `Asia/Shanghai` 月份。相同会话并发请求按提交顺序处理。证据不足时明确拒答。
- **调用尝试与结算**：每次实际提交给模型供应商的调用尝试必须有唯一调用 ID 和独立预算预留；调用前记录预留，提交供应商后标记为已提交；同一尝试的重复处理/结算按 ID 幂等，不重复计费。若重试再次调用供应商，必须创建新尝试和新 ID，独立预留并按该次实际 token/费用结算；多次供应商调用不得合并记作一次成本。仅未提交的调用可释放预留；提交后按可得 usage 结算，无 usage 时使用实施前确认的保守估算规则。
- **依赖**：依赖 Issue 01 目标环境与成本资料、Issue 02 公开内容查询、Issue 04 读者身份、Issue 05 版本/发布状态；Issue 08 验收安全、开关、故障和对账；Issue 09 使用本 Issue 的问答基线。
- **可验证验收**：固定可回答/跨文章/证据不足集；逐状态测试模型成功、拒答、供应商错误、超时；并发证明每日最多 5 次、预算不可超额；边界日/月使用 `Asia/Shanghai`；跨月结算归发起月；同一调用 ID 重复结算幂等且真实重试使用新 ID 并独立计量；验证预留、提交后结算、提交前释放；引用可验证到当时版本；越权隔离和删除级联；确认密钥不进入 bundle/响应/日志；数据政策和计价证据通过后才开放。
- **待验证/待确认**：DeepSeek 数据处理政策、实际单价与错误请求计价需在实施前按供应商当前资料验证；超时/失败无 usage 时的保守估算公式、重试次数、退避时长与提问字符/速率上限需形成可审计配置。
