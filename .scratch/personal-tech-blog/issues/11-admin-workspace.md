# Issue 11: 后台公共布局、个人中心与读者账号管理

Status: ready-for-agent
Type: task
Blocked by: 04, 05

## 目标

为个人中心和管理员设置统一采用左右布局，建立 `/admin` 下的管理员二级路由，并完成个人资料与管理员读者账号管理需求。文章管理接入公共布局时保持 Issue 05 的文章操作规则。

## 范围

### 个人中心

- 登录头像菜单将“账号设置”显示为“个人中心”。未登录访问个人中心跳转登录页。
- 页面采用左右布局。左侧展示头像、昵称、登录邮箱、手机号、性别、个人介绍、角色和创建日期；空的选填资料显示短横线 `-`。个人介绍仅本人可见。
- 右侧有“基础信息”“修改邮箱”“修改密码”三个标签页；每个标签页各有自己的保存和重置按钮。
- 基础信息包含昵称、手机号、性别、个人介绍。昵称必填；其余选填，已保存内容默认填入表单，空值显示占位提示。手机号接受中国大陆 11 位或带国家区号的国际号码，不发送短信、不标记为已验证。性别用未预选的单选项，选项为“男、女、其他、不愿透露”。个人介绍为可换行纯文本，最多 500 字。清空选填项并保存即清除对应资料。
- 基础信息重置为数据库中原已保存值；修改邮箱标签重置清空新邮箱和当前密码；修改密码标签重置清空所有密码字段。保存失败保留输入并显示安全、易懂的错误；成功提示并更新左侧资料展示；提交处理中禁用重复提交。
- 邮箱仍作为大小写不敏感的登录名，修改沿用现有表单并要求本人当前密码，不发送验证邮件。邮箱唯一性冲突时拒绝保存并提示；修改成功后撤销该用户全部会话并跳转登录，要求使用新邮箱登录。
- 修改密码沿用当前表单并要求当前密码、新密码和确认新密码；新密码至少 9 位。普通改密保留当前浏览器会话并撤销其他会话。新建读者首次设置昵称和新密码后轮换当前会话令牌并继续当前会话；管理员重置密码后的首次登录只要求修改密码。
- 暂停个人账号删除页面和 API。

### 头像

- 默认使用通用头像图标。用户仅在个人中心自行上传或更换头像，不能移除已上传头像。
- 左侧头像悬停时显示“+”；点击头像打开上传对话框。选择文件后先预览，用户点击“确认并上传”后才上传并保存。
- 仅接受 JPEG、PNG、WebP 静态图片，单张最大 5 MB；不提供手动裁剪，展示时居中裁切。本人导航和个人中心可显示头像；头像不公开，其他读者和管理员不能查看。
- 图片存储在已购买的华为云服务器私有持久目录，不直接作为公开静态资源。由服务端鉴权后只向头像本人提供图片。实施前必须验证服务器目录可写、实际上传和本人鉴权读取、Web 容器重建/Docker 重启/主机重启后的持久性，以及备份和恢复。具体服务器目录尚未确定；附件提到的 `/srv/wikilog/uploads/avatars` 是示例，不是已选路径。

### 管理员设置与账号管理

- 登录头像菜单中将“博客管理”显示为管理员专属“管理员设置”。所有管理页使用公共左右布局和独立二级路由。子菜单依次为账号管理、文章管理、AI 设置与问答。
- `/admin` 默认重定向到第一个菜单页 `/admin/readers`。未登录用户或普通 reader 访问 `/admin` 及其任何子路由时，统一显示 404 页面，并提供返回首页链接；管理员 API 对这两类身份也返回 404。不得将 reader 重定向到登录页或个人中心来代替此 404 行为。
- 账号管理页以表格列出读者。基本列为昵称、登录邮箱、账号状态和创建日期；手机号、性别不在表格列中。提供按邮箱/昵称检索及正常/已删除账号筛选。项目现有 `del_flag` 为布尔字段，软删除时设为 `true`，对应需求中的删除标记值 1。
- 每行末尾提供“编辑”“重置密码”“删除”。个人资料只在点击“编辑”后通过对话框查看和修改。管理员可编辑昵称、登录邮箱、手机号、性别；邮箱对未删除账号大小写不敏感且唯一。编辑邮箱不要求读者密码。管理员不能查看或编辑头像、个人介绍，也不能编辑角色；不提供启用/停用操作。
- 创建读者只填写登录邮箱，不填写昵称或密码；昵称可暂为空，密码固定为 `123456`。新建读者首次登录必须填写昵称并将密码改为自己的新密码，完成前不能继续使用系统。
- 点击“重置密码”先弹出二次确认框，明确提示密码将重置为 `123456`。无需线下身份确认、原因或其他人工录入。重置后要求该读者首次登录修改密码；已有昵称保留。
- 点击“删除”先弹出二次确认框，可填写选填删除原因。确认后只设置用户表的软删除标记 `del_flag = true`，保留用户和关联数据，并撤销该读者全部会话。已删除账号默认从列表隐藏，可通过已删除筛选查看并恢复。
- 软删除账号邮箱允许注册新账号。恢复前检查是否已有未删除账号占用该邮箱；若已占用，拒绝恢复并提示冲突。恢复成功后清空用户表删除原因，旧会话仍保持失效。
- 管理员创建/修改账号资料、重置密码、软删除和恢复时，自动更新用户表已有的创建人/时间或最近修改人/时间字段；删除原因保存在用户表。修改、重置和恢复无需填写原因。只保留用户表信息，不记录逐次操作日志；删除原因是唯一可填写的管理原因。
- 账号管理操作成功后给出成功反馈并刷新相应用户信息；失败时保留表单输入并显示安全、易懂的错误；处理中禁用重复提交。管理操作需服务端验证管理员角色、输入和目标状态；不得依赖客户端角色判权。

### 文章与 AI 页面边界

- 文章管理接入上述公共左右布局，文章操作权限、版本状态和现有操作规则保持 Issue 05 当前要求，不在本 Issue 扩展或重定义。
- AI 设置与问答在菜单中保留占位入口，本次不实现该页面功能，不启动 Issue 07。

## 验收标准

- 个人中心左侧信息、标签页、每页保存/重置行为、字段校验、头像上传预览/确认、私有可见性和保存反馈符合本 Issue；管理员不能读取读者头像或介绍。
- 个人中心基础信息保存后刷新左栏；选填值为空显示 `-`；昵称必填，手机号格式、性别单选和个人介绍 500 字限制生效。
- 用户头像上传前置全部通过：华为云服务器上的私有持久目录可由应用写入；上传成功后仅本人可读取；容器重建、Docker 和主机重启后文件仍可读取；完成备份恢复验证。路径不得假设为示例目录。
- `/admin` 跳转到 `/admin/readers`；匿名与 reader 访问所有管理页面和管理 API 均得到 404 页面/状态，页面含返回首页链接；admin 可以进入各独立菜单页。
- 创建读者只需邮箱，固定初始密码为 `123456`，首次登录必须设置昵称和新密码；重置密码需二次确认并提示固定密码，既有昵称保留。
- 编辑对话框只修改允许的资料；邮箱冲突安全拒绝；管理员修改邮箱后目标用户全部会话失效；表格不展示手机号、性别、个人介绍或头像。
- 软删除需二次确认并支持选填原因；结果是 `del_flag = true`、关联数据保留、会话撤销。删除账号可再注册；邮箱占用时恢复失败，邮箱未占用时恢复成功并清空删除原因，旧会话不恢复。
- 用户表自动记录创建/最近修改人和时间及删除原因；账号管理不写逐次操作日志，不提供启用/停用、硬删除、管理员编辑头像/个人介绍或读者自助删除。
- 管理操作的成功、校验失败、冲突和服务端错误均有安全反馈；失败保留输入，处理中防重复提交。
- 文章管理仅接入公共布局，文章操作行为不变；AI 页面仍为占位，Issue 07 未启动。
- 响应式与可访问性检查通过；运行 `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`。
