# Issue 02: 实现公开博客与文章搜索

Status: ready-for-agent
Type: task

## 目标

搭建本地可运行的公开博客初版与文章只读查询。使用本地 PostgreSQL 保存文章、文章版本、主分类、标签和后续账号所需的用户记录结构；不实现账号流程、文章后台、模型调用或生产部署。

Issue 01 是未来公开发版的门槛，不阻塞本地初版开发。初版完成后再评估部署平台、数据库、持久化配图、CI/CD 和公开上线。

## 范围

- TypeScript、Next.js App Router 的项目骨架和生产构建。
- 首页、主分类列表与详情、标签列表与详情、文章详情、搜索结果、关于/联系页。
- 文章元数据和当前已发布版本的只读查询；仅公开已发布版本和受控元数据。
- 建立本地 PostgreSQL schema、迁移和示例种子；文章、文章版本、主分类和标签持久化于数据库。
- 将公开查询封装为服务端数据访问模块；未配置数据库时允许使用本地 fixture 预览。
- 搜索标题和正文中文连续子串、英文不区分大小写关键词；标题命中优先，结果显示附近摘要。
- 响应式布局、可访问的导航/表单和页面元数据。

## 暂缓范围

- 生产数据库供应商选择、线上数据库配置和生产持久化验收。
- 配图对象存储、跨重新部署持久化验证与存储成本核算。
- 生产环境部署、CI/CD、线上匿名浏览验收与发版。
- 注册、登录、密码重置、收藏和问答；邮件服务在账号功能开始前再验证。

## 验收标准

- 匿名访问所有公开页不要求账号；草稿、下架文章和未发布新版本不可公开读取。
- 搜索覆盖标题与正文，中文和英文用例通过；排序和摘要可预测。
- 空结果、无文章分类和缺失文章均有明确界面；本地初版不依赖数据库凭据。
- 本地 PostgreSQL 迁移可重复执行，示例文章、分类和标签可从数据库读取；用户表包含唯一邮箱和角色/状态字段。
- 联系作者使用配置的公开 `mailto` 地址；首版无评论入口。
- 自动化测试覆盖公开/非公开文章边界、搜索行为和主要路由；项目通过 lint、类型检查、测试及生产构建。
- 本地开发服务器可运行，所有公开路由可匿名访问，并通过 lint、类型检查、自动化测试及生产构建。
- 生产环境部署、匿名浏览验收和成本门槛不属于本 issue 的初版完成条件；上线前须完成 Issue 01 与 Issue 08 的相应验收。
