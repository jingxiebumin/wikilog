# Issue 02: 实现公开博客与文章搜索

Status: ready-for-agent
Type: task
Blocked by: 01

## 目标

搭建可部署的公开博客页面与文章只读数据层。此阶段可以用最小种子文章验证页面；不实现账号、文章后台或模型调用。

## 范围

- TypeScript、Next.js App Router 的项目骨架和生产构建。
- 首页、主分类列表与详情、标签列表与详情、文章详情、搜索结果、关于/联系页。
- 文章元数据和当前已发布版本的只读查询；仅公开已发布版本和受控元数据。
- 建立文章、文章版本、主分类和标签的数据库迁移及最小种子数据，支持后续管理页上传和版本发布。
- 搜索标题和正文中文连续子串、英文不区分大小写关键词；标题命中优先，结果显示附近摘要。
- 响应式布局、可访问的导航/表单和页面元数据。

## 验收标准

- 匿名访问所有公开页不要求账号；草稿、下架文章和未发布新版本不可公开读取。
- 搜索覆盖标题与正文，中文和英文用例通过；排序和摘要可预测。
- 空结果、无文章分类、缺失文章和数据库不可用均有明确界面，不泄漏堆栈或凭据。
- 联系作者使用配置的公开 `mailto` 地址；首版无评论入口。
- 自动化测试覆盖公开/非公开文章边界、搜索行为和主要路由；项目通过 lint、类型检查、测试及生产构建。
- 完成公开环境部署和匿名浏览验收；如网站或数据库月成本超过人民币 20 元，先记录成本依据再发布。
