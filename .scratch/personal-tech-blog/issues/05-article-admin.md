# Issue 05: 实现文章上传、预览与发布管理

Status: ready-for-agent
Type: task
Blocked by: 01, 04

## 目标

在管理员设置区加入 MDX 文章和配图上传工作流，支持草稿、预览、版本发布及可恢复下架。

## 范围

- 管理员文章列表、上传 `.mdx` 与配图、预览草稿、发布、下架和恢复；不提供在线 MDX 或富文本编辑器。
- 从 MDX frontmatter 读取并校验 slug、标题、发布时间、主分类、标签和摘要；主分类使用受控集合。发布状态由服务端工作流管理，上传文件不能绕过草稿状态直接发布。
- 首版主分类从受控配置读取，不实现额外的分类管理页面。
- 同 slug 上传形成新版本，发布前当前已发布版本继续服务；发布后公开页和搜索切换到新版本。
- 配图路径在文章内可稳定解析；未随文上传的外链图片只接受 HTTPS。
- 记录版本、操作者、上传和发布时间，避免误覆盖时无法恢复。

## 安全要求

- 服务端仅接受管理员请求，校验 MIME/扩展名/大小并防止路径穿越。
- MDX 解析器仅启用明确允许的 Markdown/MDX 语法与受控组件；拒绝 import/export、脚本、任意 JSX 和未经清理的原始 HTML。
- 保存原文，但输出前进行安全渲染/转义；不得将上传内容作为可执行代码动态运行。

## 验收标准

- 草稿和预览仅管理员可见；公开页、搜索、收藏和问答只读当前已发布版本。
- 上传 slug 冲突能创建新版本而不提前替换公开版本；发布切换可追踪并可恢复。
- 下架不会删除收藏关系，重新发布后收藏恢复。
- 验证非法元数据、危险 MDX、超限/伪装文件、HTTPS 以外外链和权限绕过的测试通过。

## Comments

2026-11-11：根据已确认的领域模型补充业务规则；当前仓库没有文章管理实现、文章/版本写服务或对象存储适配器，以下均为待实现规格。负责人本人是唯一管理员，其他身份只能读取公开内容。

- **业务目标与领域规则**：维护稳定 `文章` 及其多个 `文章版本`；服务器保存的 MDX 源文和元数据是权威内容。分类受控，标签是版本快照。V1 不提供文章永久删除。
- **状态流转**：上传创建 `草稿`；发布时事务性将版本置为 `published` 并切换 `current_published_version_id`，原当前版本变为 `archived`；失败时旧发布指针不变。文章实体另有正常、下架、删除状态；下架与删除是不同的可恢复隐藏状态。恢复文章不自动发布草稿；须有有效的当前发布版本才重新公开。普通读者不能访问草稿/预览，普通页面不能访问下架/删除文章的任何历史版本；问答历史引用按 Issue 07 的保存版本证据核验。
- **历史版本读取**：已发布的旧版本保留版本地址用于核对问答引用；文章保持正常公开时，该地址可展示该具体版本并清楚标明版本；文章下架或删除时，所有普通读者版本地址均停止访问。草稿预览始终仅管理员可见。
- **权限边界**：每个上传、预览、发布、下架、删除、恢复和图片读取均重新要求负责人本人管理员身份；slug、角色、版本状态和文件 key 不接受客户端作为授权事实。读者仅能读当前公开版本。
- **正常流程**：上传时校验 frontmatter、MDX 白名单、图片类型/签名/大小及路径，将原文、结构化正文和版本关联资源保存为完整草稿；管理员预览后显式发布。已有 slug 建立新版本，不改变当前公开内容。图片上传或数据库写入部分失败时回收孤儿资源或记录待清理任务。
- **异常与边界**：无效元数据、危险 MDX、非 HTTPS 外链、伪装或超限图片拒绝；重复/并发发布需以事务和状态条件避免错误切换；存储不可用时不产生半成品草稿；删除/下架不可绕过管理员授权；孤儿图片清理与备份恢复须可追踪。
- **依赖**：依赖 Issue 01 的持久运行/图片方案和 Issue 04 的唯一管理员身份；匿名公开发版依赖 Issue 01 与 Issue 08 匿名最低门槛。Issue 06/07 依赖此处的文章 ID、当前版本与公开可见规则。

- **可验证验收**：覆盖新文章草稿、同 slug 新版本、草稿私有、事务发布切指针、旧版本归档、失败不改变旧版本、下架/删除隐藏全部普通公开路由、恢复后仅当前已发布版本可见、收藏关系保留、版本资源与源文一致、权限和文件拒绝行为；运行 `npm test`。
- **待确认**：具体图片大小/数量上限、已删除文章和图片的保留期限、孤儿资源清理时限由实施配置/负责人定值；未验证的存储服务与成本以 Issue 01 证据为准。

2026-11-12：完成本地 Issue 05 的第一阶段实现，范围限定为受限 MDX 源文、草稿、预览、版本发布和文章可恢复隐藏；配图上传暂缓，等待持久写入存储方案和权限边界确认。新增 `0004_article_sources.sql` 保存每个文章版本的 `source_mdx`，服务端解析器只生成白名单 `ArticleBlock`，拒绝 import/export、脚本、HTML、任意 JSX 和不受控 frontmatter。
