# Issue 05: 实现文章上传、预览与发布管理

Status: ready-for-agent
Type: task
Blocked by: 01, 04

## 目标

在管理员设置区加入 MDX 文章和配图上传工作流，支持草稿、预览、版本发布及可恢复下架。

## 范围

- 管理员文章列表、上传 `.mdx` 与配图、预览草稿、发布、下架和恢复；不提供在线 MDX 或富文本编辑器。
- 从 MDX frontmatter 读取并校验 slug、标题、发布时间、主分类、标签和摘要；主分类使用受控集合。发布状态由服务端工作流管理，上传文件不能绕过草稿状态直接发布。
- 首版主分类从受控配置读取，不实现额外的分类管理页面。
- 同 slug 上传形成新版本，发布前当前已发布版本继续服务；发布后公开页和搜索切换到新版本。
- 配图路径在文章内可稳定解析；未随文上传的外链图片只接受 HTTPS。
- 记录版本、操作者、上传和发布时间，避免误覆盖时无法恢复。

## 安全要求

- 服务端仅接受管理员请求，校验 MIME/扩展名/大小并防止路径穿越。
- MDX 解析器仅启用明确允许的 Markdown/MDX 语法与受控组件；拒绝 import/export、脚本、任意 JSX 和未经清理的原始 HTML。
- 保存原文，但输出前进行安全渲染/转义；不得将上传内容作为可执行代码动态运行。

## 验收标准

- 草稿和预览仅管理员可见；公开页、搜索、收藏和问答只读当前已发布版本。
- 上传 slug 冲突能创建新版本而不提前替换公开版本；发布切换可追踪并可恢复。
- 下架不会删除收藏关系，重新发布后收藏恢复。
- 验证非法元数据、危险 MDX、超限/伪装文件、HTTPS 以外外链和权限绕过的测试通过。
