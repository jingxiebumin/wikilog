# Issue 05: 实现文章上传、预览与上下架管理

Status: ready-for-agent
Type: task
Blocked by: 01, 04

## 目标

在管理员设置区提供表格化文章管理、新增/编辑对话框、独立预览页和上下架管理。文章正文由管理员上传 Markdown 文件维护；文章配置独立于文件 frontmatter。

## 范围

- `/admin/articles` 使用标准表格；列为标题、分类、标签、文章日期、创建时间、上下架状态，末列为按状态显示的操作。
- 默认按文章创建时间倒序；支持按分类、上下架状态筛选，以及按标题包含关键词筛选。分页默认每页 10 条，管理员可切换每页条数；条数选项实施时确定。
- 新增文章按钮打开对话框。标题、封面配置方式、一个分类、最多两个标签、文章日期和 `.md` 文件均在表单维护；摘要可选，日期默认当天。所有必需项完成后才可提交；保存后列表新增默认下架文章。
- 分类和标签从管理员设置的受控选项中选择；系统设置页提供分类和标签维护。
- 文章使用系统生成的数字 ID 作为稳定访问地址标识，不再使用 slug。示例为 `7699320318288494630`；具体长度/生成算法待定。此类 ID 必须按字符串安全传输和显示。
- 摘要为空时，从 Markdown 正文第一个有效段落去除格式后截取最多 120 字；标题、代码块和图片不参与摘要生成。
- 只有下架文章可以编辑。编辑可只改配置而保留现有正文；现有文件名需回显并提供下载，不提供删除文件操作。重新上传的文件仅在提交保存后替换当前正文；不保留旧正文。取消或保存失败不得替换文件。
- 新建保存后默认为下架；编辑保存不改变下架状态。业务操作只有上架、下架和删除，没有文章草稿版本发布流程。
- 上架文章可下架或删除；下架文章可编辑、上架或删除。上架、下架和删除都需二次确认。已删除文章从列表隐藏且无恢复入口；删除后的数据清理方式待确认。
- 预览按钮在新标签页打开独立预览页，仿照前台文章详情展示正文及分类、标签、文章日期、阅读时间等字段，清楚标记“预览模式”。预览仅显示已保存内容；右上角按状态显示“上架”或“下架”，操作前二次确认。
- 正文图片当前只支持可直接访问的 HTTPS 图片地址。图片自托管和富文本编辑器属于后续讨论，不要求每次另传图片文件。
- 常用表单、提示、确认框、对话框和分页使用项目内共享样式与行为，不引入 UI 组件库。
- 封面图片的输入/上传方式、删除后的数据清理语义、关闭未保存对话框的提示、数字 ID 生成长度/算法及分页条数选项仍待产品确认。

## 安全要求

- 服务端仅接受管理员请求，校验 `.md` 扩展名、文本编码及大小限制；不得将上传内容作为可执行代码运行。
- Markdown 解析器只允许已实现的安全语法，拒绝脚本、原始 HTML 和危险链接协议；正文图片外链仅允许 HTTPS。
- 文件替换先暂存，只有文章表单整体提交成功后才替换当前源文；失败保留当前文件。
- 每项上架、下架和删除操作重新验证管理员身份、目标文章状态及确认意图；预览需管理员授权，不能因链接可猜测而公开下架文章。

## 验收标准

- 新增文章必须一次提交有效配置和 `.md` 文件；保存后为下架且不出现在任何公开查询。
- 下架文章的配置修改可不上传文件；重新上传只在保存成功后替换当前文件，失败/取消保留原文件。
- 上架文章不可编辑；下架、上架、删除均二次确认；下架时收藏关系保留，上架后恢复显示。
- 预览在新标签页呈现保存后的正文和文章元数据，标记预览模式，并提供按状态对应的上架/下架按钮。
- 文章列表列、默认排序、筛选及分页符合范围；已删除文章不显示且没有恢复入口。
- 自动摘要取首个有效段落、去格式并最多 120 字；空段落、标题、图片和代码块不能成为摘要来源。
- 验证非法 Markdown、危险语法、超限文件、非 HTTPS 图片链接和权限绕过。

## Comments

2026-11-11：根据已确认的领域模型补充业务规则；当前仓库没有文章管理实现、文章/版本写服务或对象存储适配器，以下均为待实现规格。负责人本人是唯一管理员，其他身份只能读取公开内容。

- **业务目标与领域规则**：维护稳定 `文章` 及其多个 `文章版本`；服务器保存的 MDX 源文和元数据是权威内容。分类受控，标签是版本快照。V1 不提供文章永久删除。
- **状态流转**：上传创建 `草稿`；发布时事务性将版本置为 `published` 并切换 `current_published_version_id`，原当前版本变为 `archived`；失败时旧发布指针不变。文章实体另有正常、下架、删除状态；下架与删除是不同的可恢复隐藏状态。恢复文章不自动发布草稿；须有有效的当前发布版本才重新公开。普通读者不能访问草稿/预览，普通页面不能访问下架/删除文章的任何历史版本；问答历史引用按 Issue 07 的保存版本证据核验。
- **历史版本读取**：已发布的旧版本保留版本地址用于核对问答引用；文章保持正常公开时，该地址可展示该具体版本并清楚标明版本；文章下架或删除时，所有普通读者版本地址均停止访问。草稿预览始终仅管理员可见。
- **权限边界**：每个上传、预览、发布、下架、删除、恢复和图片读取均重新要求负责人本人管理员身份；slug、角色、版本状态和文件 key 不接受客户端作为授权事实。读者仅能读当前公开版本。
- **正常流程**：上传时校验 frontmatter、MDX 白名单、图片类型/签名/大小及路径，将原文、结构化正文和版本关联资源保存为完整草稿；管理员预览后显式发布。已有 slug 建立新版本，不改变当前公开内容。图片上传或数据库写入部分失败时回收孤儿资源或记录待清理任务。
- **异常与边界**：无效元数据、危险 MDX、非 HTTPS 外链、伪装或超限图片拒绝；重复/并发发布需以事务和状态条件避免错误切换；存储不可用时不产生半成品草稿；删除/下架不可绕过管理员授权；孤儿图片清理与备份恢复须可追踪。
- **依赖**：依赖 Issue 01 的持久运行/图片方案和 Issue 04 的唯一管理员身份；匿名公开发版依赖 Issue 01 与 Issue 08 匿名最低门槛。Issue 06/07 依赖此处的文章 ID、当前版本与公开可见规则。

- **可验证验收**：覆盖新文章草稿、同 slug 新版本、草稿私有、事务发布切指针、旧版本归档、失败不改变旧版本、下架/删除隐藏全部普通公开路由、恢复后仅当前已发布版本可见、收藏关系保留、版本资源与源文一致、权限和文件拒绝行为；运行 `npm test`。
- **待确认**：具体图片大小/数量上限、已删除文章和图片的保留期限、孤儿资源清理时限由实施配置/负责人定值；未验证的存储服务与成本以 Issue 01 证据为准。
