# Issue 01: 验证运行平台、数据库与配图存储

Status: ready-for-agent
Type: research

## 目标

验证 TypeScript/Next.js App Router、CloudBase 上海 PostgreSQL 和可持久化配图存储能否支持公开博客及后续受保护写操作，并核算试用结束后的月度成本。

## 工作

- 对比并验证满足 Next.js App Router 的部署方式，记录大陆访问、部署限制、环境变量和持续费用。
- 验证 CloudBase PostgreSQL 连接方式、迁移/备份能力、连接限制、访问延迟和试用后的持续费用。
- 为 MDX 附图验证私有凭据只在服务端使用、公开读取、文件大小/类型限制和持续存储成本所需的对象存储方案。
- 检查网站与数据库月度总成本目标是否在人民币 20 元以内；明确列出未计入或按量变化的费用。

## 验收标准

- 提交简短验证记录，说明选项、实测证据、推荐运行配置、月成本估算和未通过项。
- 公开页面可在不向浏览器暴露数据库凭据的条件下读取已发布文章所需数据。
- 配图在重新部署后仍可读取，删除与访问策略清楚。
- 若试点失败，提供仍可实现公开博客的替代配置，并在获得负责人决策前不锁定长期供应商。
- 仅在有真实架构承诺时新增/更新 ADR；不为试点测试创建线上用户数据。
