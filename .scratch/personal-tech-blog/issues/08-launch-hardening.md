# Issue 08: 完成首发安全、恢复与发布检查

Status: ready-for-agent
Type: task
Blocked by: 01, 02

## 目标

验证匿名公开博客及后续已批准读者功能在生产配置下安全、可恢复、费用可观察，并落实条件性功能开关。本 Issue 分为匿名发布最低门槛和完整读者功能门槛：匿名公开发布必须先通过 Issue 01 与本 Issue 的匿名最低验收；完整读者功能只能在本 Issue 完整验收后启用。Issue 04–07 不阻塞匿名最低验收，但属于完整验收的前置条件。

## 验收标准

- **匿名最低验收**：Issue 01 的目标环境、持久化/恢复和访问验证通过；本 Issue 完成匿名读取边界、生产密钥配置、PostgreSQL 与文章图片备份/恢复演练及回滚检查。通过后只允许开放匿名只读博客。
- **完整验收**：在匿名最低验收基础上，Issue 04、05、06、07 均已完成；验证生产环境密钥只存于服务端密钥配置，认证、管理员操作、上传和问答端点有授权、限速及输入校验。
- 数据库故障、对象存储故障和模型超时均有安全降级，不泄漏内部数据；系统不发送邮件。
- 有 PostgreSQL 和文章图片的备份/恢复流程，并完成一次恢复演练。
- 记录网站/数据库实际成本核验方式；记录模型供应商用量与应用估算对账方式及告警阈值。
- 匿名最低门槛通过后可单独部署公开博客；完整门槛未通过时注册、登录、收藏和问答保持关闭；模型政策/预算门槛未通过时问答关闭。
- 完整验收完成后，完成匿名、读者、管理员三个角色的端到端验收，并执行 lint、类型检查、测试和生产构建。
